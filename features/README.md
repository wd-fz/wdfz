# 功能模块

每个功能使用独立目录：

| 目录 | 职责 |
| --- | --- |
| `demo/` | M0 告示牌示例，保留旧测试场景与存档 |
| `inventory/` | 8 格背包、两个快捷栏、地面物品状态及拾取表现 |
| `investigation/` | 首条调查、钥匙来源、门状态与场景投影 |
| `player/` | 玩家数值初值、边界、SAN 对应体力上限与保存 |

规则继承 [FeatureModule](../core/modules/feature_module.gd)，在 [GameApp._make_session](../app/game_app.gd) 注册。模块 ID 和交互 ID 使用稳定命名空间，不从场景路径或中文显示名推导。

一个功能可以同时拥有规则与表现适配器：规则对象不继承 Node；表现脚本可与自己的场景一起放在功能目录。逻辑状态只由规则拥有，表现可以销毁、重建或暂时缺席。

新功能的完整接入步骤、协议和旧版映射见[移植接入指南](../docs/移植接入指南.md)。
