# 应用图标

`icon.svg` 沿用旧 Android 壳的「半开教室门与冷光」图标，将原 Android VectorDrawable 的路径和背景颜色直接转写为 SVG，供 Godot 桌面与 Android 导出使用。

来源：[wd-fz/wd-fz.github.io@4e247e3](https://github.com/wd-fz/wd-fz.github.io/tree/4e247e37cd96ac1ae98ab4413cae62216b5657d2/android/app/src/main/res/drawable) 的 `ic_launcher_foreground.xml`、`ic_launcher_background.xml`。许可证沿用原项目 GNU AGPL v3；没有引入第三方图标。
