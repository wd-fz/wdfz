## 来源与分发

2026-11-10，根据项目用户要求，通过 OpenAI 图像生成功能生成；原始生成结果保留在工作区的 `generated_images/`，本目录保存游戏副本。图像随项目按根目录的 [LICENSE](../../../LICENSE) 分发。未采用第三方插画或品牌标志。

统一方向是现代中国校园怪谈：旧纸、校服、磨损金属与日常工具，手绘质感，墨色、灰绿、暖白、铜色及少量暗红。蛾群为黑色。生成图不承载可读的名称、数值或规则；文字、按钮、计时与焦点仍由引擎绘制。

## 资源结构

- `atlases/` 保存未经像素编辑的生成 PNG。
- 各分类目录中，一个稳定 ID 对应一个独立 `AtlasTexture`，共享源图而不复制像素。
- `catalog.json` 记录全部 ID 与纹理路径。
- 第一轮排列见 [build_ui_atlases.py](../../../tools/art/build_ui_atlases.py) 的 `SHEETS`；第二轮排列见 [expansion_sheets.json](expansion_sheets.json)。均按从左到右、从上到下排列，文件名将稳定 ID 的 `:` 和 `.` 转成 `_`，不改动玩法 ID 或存档。
- 运行 `python tools/art/build_ui_atlases.py` 可重建所有 `.tres` 和目录清单；工具会验证重复 ID、文件名碰撞及物品完整覆盖。
- [UIArt](../../../game/presentation/ui/ui_art.gd) 只负责表现层加载与缓存。

## 展示规则

未解锁的成就、死亡、演出与评级共用封存图；未发现的秘密档案仍不出现在列表中。直接解锁某档评级的示例不展示未发现的结局图片。笔记路线按钮使用对应工具图，不用结局缩略图。

地图保留真实建筑轮廓、楼层格子、探索遮罩、文字与玩家标记。地标图只画在实际对象所在位置，并在空间足够时显示。楼梯和电梯图标只出现在已探索且原本有对应标记的格子。选择列表与弹出菜单均限制图标尺寸。

插画不接收鼠标或触摸事件。移动端小按钮只有在文字与图片都能放下时才显示图片，保留原触控范围。大图位于可滚动内容中，关闭与返回按钮保持可达。原有实景菜单照片、3D 演出、贪吃蛇棋盘与评级动画继续使用。

## 验证与实拍

[ui_illustrations.gd](../../../tests/suites/ui_illustrations.gd) 从真实物品、天赋、成就、DLC、档案与评级定义检查覆盖、独立区域、图集边界、非法 ID 与缓存。界面检查使用真实触摸事件，覆盖横屏小窗口、大字号、封存与秘密条目、评级示例保密、地图探索遮罩以及触屏按钮边界。

导出冒烟会读取打包后的目录清单，逐个加载全部 234 个纹理资源及背景，防止动态加载路径在源代码运行正常、导出后丢失。

[第一轮实拍](../../../pictures/物品天赋与手机插画/)与[第二轮实拍](../../../pictures/界面与档案插画/)均从正式游戏界面采集。第二轮脚本为 [capture_ui_expansion.gd](../../../tools/capture/capture_ui_expansion.gd)，使用独立示例存档、控制的笔记与档案解锁和示例结算，包含 1280×720 与 844×390 横屏；不是自然通关记录。画质调低仅用于界面验收，竖屏不在维护目标内。

2026-11-10 本地验证：完整无窗口回归 17,346 项检查、0 失败；Vulkan Forward+ 插画与文档专项 981 项、Mobile 专项 982 项，均无引擎错误。地图图标阈值最后按实际截图调整，并重新采集验收。Linux PCK 从独立目录启动，全部插画和背景加载及导出冒烟通过。这些是软件 Vulkan 验证，不等于 Android 真机测试。
