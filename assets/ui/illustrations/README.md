# 游戏界面插画

这些是直接加载到游戏的素材：41 件物品、7 个天赋、随机天赋图、7 个手机应用、手机电池图和手机主页背景。物品 ID、天赋规则及存档格式沿用既有定义。

## 来源与分发

2026-11-10，根据项目用户的要求，通过 OpenAI 图像生成功能生成；原始生成结果保留在工作区的 `generated_images/`，本目录保存用于游戏的副本。图像随项目按根目录的 [LICENSE](../../../LICENSE) 分发。未采用第三方插画或品牌标志。

统一方向是现代中国校园怪谈：旧纸、校服、磨损金属与日常工具，手绘质感，墨色、灰绿、暖白、铜色及少量暗红。生成图不承载物品名称、天赋效果或功能按钮；可读文字、交互、布局与焦点仍由 Godot 控件完成。

## 资源结构

- `atlases/`：未经像素编辑的生成 PNG。物品和应用采用透明底；天赋采用带透明边缘的插画；手机背景为不透明横幅。
- `items/`、`talents/`、`phone/`：每个稳定 ID 对应独立的 `AtlasTexture` 资源，引用原图区域，共享显存；不是将整张图集作为界面截图。
- `catalog.json`：ID 与纹理资源的完整对应表，供覆盖检查使用。
- `game/presentation/ui/ui_art.gd`：只负责加载和缓存纹理，未进入玩法规则或存档模块。

图集按从左到右、从上到下排布：前两页物品各 4×4，第三页 3×3；天赋和手机应用各 4×2。精确对应关系在 [资源生成工具](../../../tools/art/build_ui_atlases.py) 的 `SHEETS` 中；运行 `python tools/art/build_ui_atlases.py` 可重建 `.tres` 与目录清单，不改动原 PNG。新增物品时须补素材并更新对应表，回归会检查完整覆盖。

接入位置：背包物品卡、桌面快捷栏、触屏快捷按钮、天赋选择卡、手机应用导航及手机背景。图像控件不接收鼠标或触摸事件，操作仍落到原按钮。

## 接入验证

`tests/suites/ui_illustrations.gd` 根据物品、天赋和手机应用的实际定义逐项检查资源覆盖、不同 ID 的独立区域、图集边界及缓存；用真实触摸事件选择天赋、使用物品和切换应用，并检查横屏大字号与清空快捷栏后的图标。

2026-11-10 本地完整无窗口回归通过；Vulkan Forward+ 与 Mobile 专项各 216 项检查、0 失败。Linux 导出 PCK 在独立目录运行，全部物品、天赋、应用、随机天赋、电池及背景可加载，导出冒烟检查通过。图像表现和输入检查使用软件 Vulkan，不等于 Android 真机验收。

[游戏内实拍](../../../pictures/物品天赋与手机插画/) 由 `tools/capture/capture_ui_illustrations.gd` 使用正式界面采集，包含 1280×720、844×390 横屏与大字号；库存和机位经过控制，截图不是自然通关记录。
