# 界面与档案插画实拍

这些 PNG 来自正式 Godot 界面，以 Vulkan Forward+ 在本地软件渲染设备上采集，不是界面设计稿。

| 文件 | 内容 |
| --- | --- |
| 01-menu | 主菜单和功能图标 |
| 02-achievements | 已解锁与封存成就 |
| 03-archive | 死亡记忆缩略图与重看入口 |
| 04-settings | 设置导航和五档画质图标 |
| 05-results | 示例 S 评级、原有盖章动画和结局插画 |
| 06-notes | 调查目标、最近发现、分类图标和笔记卡片 |
| 07-campus-map | 数据绘制的总图、实际地标位置和人物标记 |
| 08-floor-mobile | 844×390 横屏楼层草图及选择器 |
| 09-notes-mobile | 844×390 横屏、大字号和触屏操作 |
| 10-ending-mobile | 带配图的可滚动结局卡 |
| 11-death-mobile | 带配图的死亡记录及固定返回按钮 |
| 12-menu-mobile | 小横屏主菜单 |

采集脚本：[capture_ui_expansion.gd](../../tools/capture/capture_ui_expansion.gd)。使用隔离存档、控制的五类示例笔记、直接解锁的少量档案和调试示例结算；不是自然游玩通关证据。宽屏为 1280×720，小横屏为 844×390、文字 125%。画质调至流畅只为检查界面，Android 真机表现需另行验收。

素材目录与接入规则见[插画说明](../../assets/ui/illustrations/README.md)。
