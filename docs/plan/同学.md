# 同学

以固定旧版 `domain/classroom-layout.js`、`app/classmates.js`、`fx/classroom.js` 与 `broadcast-view.js` 的运行结果为准。状态见[计划目录](README.md)，证据见[迁移一致性验证](../迁移一致性验证.md)。

## 规则与表现边界

`ClassmatesModule` 保持占座、不能翻抽屉、违规压力与堵门规则。`ClassmatesView` 单独管理人物、朝向、起身和行走；人物没有额外碰撞，不修改占座记录、规则随机序列或玩家位置。

- 教学楼五层、每层四间教室，沿用原种子排座。自己与同桌空着，本班最多 36 人，全层最多 50 人；自己的教室另有老师，站在黑板与讲台之间。
- 正常状态面向黑板。违规 35–69 时缓慢转头，70 起按原速度起身围拢，92 起围到最近的门前；原规则模块决定门是否锁住。降低违规不擅自重置原版保留的姿态。
- 全体回头异象使用更快的转头速度，转到正面后站起，异象结束并满足条件时坐回去。短暂环境注视及次日少一个座位沿用原环境模块；长铃离校时优先走向楼梯。
- 平时为原黑色不受光人形。完整版开场前先建好同学，演出中切换正常受光材质与黑影；只展示一个老师，结束、跳过、取消都恢复正式场景。
- 长铃时更换站姿，沿导航网格以原 1.4 米／秒前往楼梯，抵达后隐藏。铃停恢复原座位、朝向和坐姿；切场景、重开及菜单释放显示节点。

## 验证

`tools/export_reference.py --classmates-only` 直接运行原代码，采集普通注视、围拢、堵门、异象回头、恢复与离校的八组时间轴。`tests/suites/classroom_motion.gd` 比较老师与所有同学的坐标、朝向、姿态、站起进度和可见性；使用原路径隔离运动积分，再在五层分别运行原生导航至长铃结束。

正式新局验证开场前已有人物、材质实际切换、老师不重叠、取消不污染会话。受控实拍入口为 `tools/capture/capture_classmates.gd`；不替代自然随机长局和移动端真机验收。
