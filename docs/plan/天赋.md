# 天赋

每局一个天赋。新局在难度之后选择六种天赋之一，也可随机抽取。规则版本为 5，天赋定义位于 `game/features/story/talent_module.gd`。

## 待办与进度

| 天赋 | 状态 | 接入点 |
| --- | --- | --- |
| 科技党 | 已完成 | 开局拥有满电手机；手机耗电翻倍 |
| 编程社 | 已完成 | 不带 U 盘也能操作网络中心终端；西小门第一次答错不扣 SAN（仍换题） |
| 车感好 | 已完成 | 在车库给正确车辆描边高亮。没钥匙也能搭线（4.8 秒，有钥匙时用钥匙 1.6 秒） |
| 暗处适应 | 已完成 | 随日落自动开启夜视，提亮暗处并带有浅绿色滤镜。车库与熄灯后室外的危险区消耗 ×0.55 |
| 天生免疫 | 已完成 | 每局一次挡下致命事件（身上有药丸时先用药丸）；之后 SAN 至少 45、违规至多 40、巡察者退开 |
| 顺风耳 | 已完成 | 绘制 15 米内巡察者的隔墙轮廓，雷达随朝向显示相对方位和距离 |
| 选择界面 | 已完成 | 六张天赋卡和「随机天赋」。左侧浏览、右侧详情，确认后开局。暂停时显示当前天赋与剩余次数。[触屏列表与天赋选择](../触屏列表与天赋选择.md) |
| 成就 | 已完成 | 使用六种天赋分别达成一次公开真结局，解锁「六种活法」 |

单人和合作均按本地玩家自己的天赋显示效果。恢复单人或合作旧存档时，「守时」归为无天赋。旧 Web 存档中的非现行天赋也归为无天赋。

## 开场（前情提要）

选完天赋后播放旧版 `prologue.js` 的 11 页前情提要（每页 3.4 秒，E／空格／点击翻页，Esc 或「跳过」结束），期间游戏暂停；结束后提示「第四节。我坐在自己的位子上……」并记成就「第四节」。旧版的眼皮开合与同学翻转演出未移植。截图 `pictures/天赋/03-开场-前情提要一页.jpg`。两种模式各 **811 项断言，0 失败**。
