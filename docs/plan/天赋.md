# 天赋

每局一个天赋。**规则照旧版**（`wd-fz/wd-fz.github.io@0bf508a` 的 `talents.js`，规则版本 4）：七个可选天赋的名称、效果、限制与数值；新局在难度之后选择（或随机）。规则在 `game/features/story/talent_module.gd`，各模块只问「能不能／怎么做／倍率多少」。
