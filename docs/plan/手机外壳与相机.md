# 手机外壳与相机

手机界面、纸飞机小游戏与相机应用，**照旧版**（`wd-fz/wd-fz.github.io@0bf508a` 的 `phone.js` 与 `modules/phone-camera/camera.js`）。此前手机是一个选择框；现在是一块面板：电量与网络状态、七个应用按钮、当前应用的说明与操作、纸飞机画面、相机页与相册。工具查看时不能移动，世界仍在运行。规则在 `features/phone/plane_game.gd`（纸飞机）与 `features/phone/camera_module.gd`（相机），合成照片在 `app/photo_studio.gd`，界面在 `ui/phone_panel.gd`，接线在 `app/game_app.gd`（`_open_phone`、`_phone_paint`、`_phone_shell_step`、`_shoot`）。
