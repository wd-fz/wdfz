# 粉笔笔触贴图

旧版 `modules/chalk-marks/marks-fx.js`（`wd-fz/wd-fz.github.io@0bf508a`）：每种粉笔记号一张手画的 128 px 贴图（线条有抖动与断续，每笔画两遍——外一圈灰粉笔灰、里面白芯，再随机擦掉颗粒），贴在地上或墙上，受场景光照。Godot 版此前是文字标签（X ↑ O ← → △ ? 正）。
