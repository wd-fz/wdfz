# 人形模型

把 Godot 版里所有「胶囊体当人」的占位换成旧版（`wd-fz/wd-fz.github.io@0bf508a`）`model/figure.js` 的人形。**模型不在 Godot 里另画**：`tools/export_scenes/export_scenes.py --only figures` 在旧版页面里调用 `figMesh`，导出 `assets/campus/figures/{tall,roam,person,teacher,neck,sit}.glb`；`game/presentation/world/campus/figure_model.gd`（`FigureModel.make(kind, color, unlit, scale)`）负责实例化、上色（顶点色 × 色调）。导出的朝向是 +z，加载时转半圈成 Godot 的前方 -z。

## 与旧版的差异

- 旧版另有 Blender 建的人形资产（`fig_*`）优先于这套代码建模；本版导出的是旧版在第 2 档画质下实际使用的那一套。
- 人形不带骨骼动画（旧版也是静态几何，走动靠整体位移）。

## 验收

- 无窗口全量测试 1209 项、0 失败；`tools/capture/capture_figures.gd` 与 `capture_classroom.gd` 的截图（`pictures/人形模型/`）。
- 穿模检查（CLAUDE.md，改了建模）：人形都是视觉节点，不带碰撞；学生会检查队列的碰撞盒原样保留（尺寸未变）。教室同学坐在原来胶囊的位置，座位与课桌的几何不变，不影响可达性。
