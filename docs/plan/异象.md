# 异象

按 `wd-fz/wd-fz.github.io@0bf508a` 的真实运行时移植调度、全部 26 种规则及其表现。计划状态统一见[计划目录](README.md)，运行证据见[迁移一致性验证](../迁移一致性验证.md)。

## 规则与边界

- 保留权重、位置／时间资格、冷却、上课选择、预警兑现、危险优先级、SAN／违规后果、死亡保护与可乐欠账。
- 原生存档记录当前异象、判定位置、剩余选择时间、历史、预告、欠账和随机状态；导入旧档后继续本局。渲染不能消费玩法随机数或改动玩家镜头。
- 模块负责触发与结算，应用边界连接音效、调查笔记、成就、积分与死亡演出；场景表现只读模块状态。

## 场景表现对齐

`AnomalyFx` 负责切换和清理，`AnomalyProps` 保留原世界道具的几何、尺寸、位置和动画：

- 做操恢复六个黑影及逐人的俯身节奏；隔间手恢复手掌和四根手指，固定在原前方落点。
- 仪式圈按判定的 2.1 米半径、44 段粉笔线、五角星、中央暗渍与四根蜡烛绘制；火焰沿原节奏变化。
- 渗水的五个水渍、十五道滴水与天花板污渍跟随规则落点；黑板与名单吸附原墙面，不再随着镜头漂浮。
- 广播扬声器、顺次亮起的走廊灯、移动窗格、冷库地面霜、后桌、天台分身、围墙外长颈行人和影子按原模型与动画恢复。
- 盛宴恢复长桌、餐具、食物、食堂灯笼与布条；目光恢复五档数量的杏仁形金／红眼睛、睁眼进度与注视反应。
- 雨点成字使用原运行时文字贴图，不另画普通雨；原拍肩事件不额外生成一直跟随玩家的占位人物，笑脸仍走独立事件表现。
- 雨与蛾群交给 `WeatherFx`，声音、现场痕迹及调查记录已有独立实现，不能再列为“未移植”。

## 验证方法

`tools/export_reference.py --anomaly-fx-only` 运行旧源码，采集 17 种效果、五档目光数量，共 21 组模型与 147 个动画状态，导出原眼睛／文字贴图及灯笼模型。`tests/suites/anomaly_fx.gd` 比对位置、尺寸、方向、缩放、颜色、透明度、显隐和动画，另覆盖固定墙面、同种异象重启、结束清理与规则状态隔离。

`tools/capture/capture_anomaly_props.gd` 在真实校园中采图；机位、事件与时间受控，不能冒充自然随机游玩。早期占位批次的 429 项验收及 `pictures/异象/`、`pictures/异象画面/` 是历史记录，当前结果另记。

## 后续核对

- 水杯与可乐恢复原五档模型、文字与波纹贴图、警示圈、弹道、变形、脱落杯盖、碎片／泡沫和落地水渍。落点从实际校园模型取地面高度，表现不改变碰撞或异象判定。
- 静态及动态痕迹恢复原哈希与全局序号、平面几何、颜色和杯子残骸；同数量替换痕迹与切换画质会重建模型。
- `--falling-props-only` 与 `--traces-only` 从旧运行时采集动画、模型、地面与痕迹样本；对应回归位于 `tests/suites/falling_props.gd`、`tests/suites/traces.gd`。
- 检查不同场景、质量档、遮挡和真实设备的视觉可读性；软件 OpenGL 截图不代替全部图形设备。
- 自然随机长局、声音方向和实际听感、暂停／读档／死亡交接继续验收。
