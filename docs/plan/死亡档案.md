# 死亡档案（CG 档案馆）

主菜单「档案馆」（`features/story/death_archive.gd`）。**照旧版**（`death-archive.js` 的 `DEATH_ARCHIVE` / `ARCHIVE_CUTS`）：每种真实死因第一次发生时解锁一份档案，同一种再死只记次数；结局达成后也收进来。解锁前只显示编号与「？？？」，解锁后显示名称、次数与一句记录。

## 验收

两种模式各 **504 项断言，0 失败**（档案 16 项、演出 4 项）：计数与解锁、重复只加次数、未见的保持锁定、不含迷宫死法、每个条目都是真实的死亡来源（对照 `StoryModule.SOURCES` 与异象表）、菜单能打开。截图 `pictures/死亡演出/`。**未验证**：自然死亡后档案里是否按预期出现（由死亡记录单元验证，没有端到端游玩）。
