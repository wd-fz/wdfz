# 建模与光影优化

用户 2026-11-10 要求「优化建模和光影」，并确认了范围：

- 人形外观：**圆润无脸人形**——保留旧版「没有脸的灰色人」，只把身体做圆润、比例自然；异象里的黑色剪影照旧。
- 建模范围：普通人形（同学、老师、路人、坐姿）、巡察者与怪异人形（高个子、车库里那个、长脖子）、第一人称的手、场景材质质感。
- 光影：修正灯管过曝的光晕；加上白天室内窗户照进来的日光与窗影。

本计划接手并取代[手部与人物建模重做](手部与人物建模重做.md)里「未开始」的建模项。只改外观与光照：身高、体量、站位、碰撞、巡察者判定、课表与数值都不变（CLAUDE.md「玩法与建筑都不能变」）；建筑与家具的形状不动，只调材质参数。

## 做法

**人形与手：造型数据取自旧版，曲面重新生成。** 旧版 `model/figure.js` 的人形是几十个椭球、圆台和倒角块拼出来的，手（`hands.js`）是沿指节扫出的椭圆管；导出成网格后每一块各自成面，接缝生硬、棱角分明。新流程：

1. `tools/remodel/capture.js` 注入旧版页面，在它自己生成人形／手的时候记下每个基本体的参数（位置、半径、颜色），不改旧版代码，写成 `tools/remodel/primitives/*.json`。
2. `tools/remodel/remodel.py` 把这些基本体当成有向距离场做平滑并集（相邻的肢体自然融合，不再有接缝），用 marching cubes 取等值面，按距离场的梯度算平滑法线，减面后写成 GLB，替换 `assets/campus/figures/`、`assets/campus/patrol/`、`assets/campus/hands/` 里的同名文件。
3. Godot 侧的调用方式不变（`FigureModel.make()`、`HandsView`）；网格的 LOD 由导入器生成，各画质档用已有的 LOD 阈值。

这样比例、身高、姿势、握持与旧版逐一对应，只有表面变圆润。

**场景材质：** 导出的建筑材质没有保留旧版的材质种类名，只能按贴图与参数识别；在加载房间时按粗糙度档位归类（地面、木、墙、金属、玻璃），调整粗糙度与高光，不换贴图、不动几何。

## 约束

- 新人形的包围盒与旧模型对照，高度误差不超过 2 cm；坐姿的手仍搭在课桌面上、不穿进书本。
- 黑色剪影（异象、分镜）继续用不受光的单色材质，新网格只改变轮廓的圆润程度。
- 死亡演出里单独的手、头、突脸等（`assets/campus/fx`）不在这一轮范围内。
- 隐藏内容用到的人形只在内部材料里跟踪，不写进公开文档。
- 重建工具依赖 Python 的 numpy、scikit-image 等，只在开发机上运行；运行时不依赖。
