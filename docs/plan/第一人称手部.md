# 第一人称手部

旧版 `hands.js`（`wd-fz/wd-fz.github.io@0bf508a`）：开手电、撑伞、玩手机时，画面下方看得见自己的手和手里的东西。**模型照搬旧版**：`tools/export_scenes/export_scenes.py --only hands` 调用旧版的 `handArm`／`handGeo`／`makeHandItem`，导出 `assets/campus/hands/{torch,phone,brolly}_{L,R}.glb`（手＋袖口＋物件，顶点色）与 `place.json`（旧版 `HAND_PLACE`）。`actors/hands_view.gd`（`HandsView`）挂在玩家相机上。
