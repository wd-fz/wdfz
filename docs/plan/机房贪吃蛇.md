# 机房贪吃蛇

机房电脑旁的小游戏，**照旧版**（`wd-fz/wd-fz.github.io@0bf508a` 的 `pcgame.js`）。「玩一会儿电脑」这项休息（游戏时间 15 分钟、+12 SAN、冷却，在设施计划里）做完后，接着开贪吃蛇；退出时按得分再回一点 SAN。规则在 `features/phone/snake_game.gd`，界面在 `ui/snake_panel.gd`，接线在 `app/game_app.gd`（`_start_snake`、`_stop_snake`、`_snake_step`）。

## 差异

旧版开电脑时已按活动扣过时间，退出不再跳时间；这里同样。旧版「PC.on」让开着的游戏计入多处暂停判定；这里只对氛围系统生效，其余（巡察者、异象）照常运转，与旧版世界在小游戏时仍推进的说明一致。

## 验收

无窗口模式 **1089 项断言，0 失败**：开局状态与倒计时、步长、吃到变长与计分、不能原地掉头、滑动在下一步生效、按键压过滑动、撞墙与撞自己结束、奖励公式（含休息系数与上限 20）、成就 7 个解锁。截图 `pictures/机房贪吃蛇/`（`tools/capture_snake.gd`）。**未验证**：窗口模式下真人键盘与触屏的实机操作。
