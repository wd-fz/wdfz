# 规则怪谈DLC与原生扩展

参照固定旧版 `game3d/mods/campus-rules.js` 1.1.0；整体状态见[计划目录](README.md)，实际运行证据见[迁移一致性验证](../迁移一致性验证.md)。

## 保留的体验

- 主菜单与暂停页提供「DLC 与模块」。规则怪谈默认关闭；切换只影响新局，读档使用存档里的模式与规则组。
- 四套经过校验的规则组使用原 UTF-16 字符串哈希选择，不消耗玩法随机流。载体位置、原文、手册条目与「可信／存疑」批注保留；玩家界面不直接显示规则真假。
- 宿舍熄灯后累计八秒触发三声敲门；后两声分别延迟 1.8、3.6 秒，离开场景、死亡、读档、重开及菜单取消旧回调。每晚只触发一次。延迟声按实际时间运行，暂停不会重复触发。
- 饭点食堂餐券每天一次；上课在教学楼累计二十五秒触发借名，每天一次。离开教学楼保留借名累计时间；已有选择窗口不累加这些触发计时。
- 危险纸飞机使用 DLC 内页；读过的规则与证据、事件完成日期、途中计数、批注和可信标记跟随存档。
- 七项模式成就与专属死亡档案单独展示，不提供加成，不写本体成就。真实通关带 `rules@1.1.0` 模式字段，不进入本体最佳、排行或评级取得统计。调试导致的失信标记不能用关闭面板或读档撤回。
- 「门外有你的名字」沿原七秒时间轴播放，保留门、脚、名牌、描黑动画、镜头与字幕。

## 实现边界

`RulesDlcModule` 只接收内容和上下文，负责规则组、进度、选择结算和独立记录；不访问文件、窗口或输入。`RulesDlcFlow` 连接菜单、事件、场景生命周期、手册与本机记录。`RulesDlcProps` 仅显示小纸片，没有额外碰撞。专属死亡使用已有 `DeathCG`。

旧存档转换识别 `rt.rulesMode` 与 `mods["mod:campus-rules"]`。1.0.0 缺少组号时按 A 组；未知版本、非法组号与损坏状态拒绝安装，现有游戏不被替换。普通旧 Godot 存档没有新模块时默认关闭。

外部 JavaScript 模组不能直接在 Godot 中执行。当前菜单列出内置模块，不提供声称能执行旧 `.js` 的上传按钮；自定义扩展仍需明确原生接口、依赖、生命周期与存档版本，不以此内置模式代表通用模组迁移完成。

## 验证

`tools/export_reference.py --rules-dlc-only` 直接运行旧 DLC，采集规则组、261 个种子、全部载体、240 组触发条件、六个选择结果、四套规则的原存档与 141 帧死亡时间轴。`tests/suites/rules_dlc.gd` 对照这些样本，并验证模式开关、选择与控制恢复、跨场景回调取消、复活、笔记批注、保存／读档、可信记录与排行隔离。

原生截图入口为 `tools/capture/capture_rules_dlc.gd`，使用受控位置和时间，通过实际交互触发；不代替自然长局或 Android 真机验证。档案回放与通用扩展另列后续缺口，不能因此批规则测试通过而宣称全项目迁移完成。
