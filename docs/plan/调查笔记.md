# 调查笔记

状态见[计划目录](README.md)，当前验证见[迁移一致性验证](../迁移一致性验证.md)。

玩家的调查记录与「手册的笔记页」，**照旧版**（`wd-fz/wd-fz.github.io@0bf508a` 的 `investigation.js` 与各记录点）：只由真实交互写入；记录有类型（事实／推测／验证／线索）、地点和获得日，最近八条会被记住；「当前调查」卡片给出所关注路线的目标，路线进度块逐条列出。规则在 `game/features/story/investigation_module.gd`，界面在 `game/presentation/ui/game_ui.gd` 的 `show_notes`（暂停页「笔记」按钮，或按 N），接线在 `game/app/game_app.gd`（`_invest_context`、`_record`、`_apply_invest_events`、`_show_notes`）。

| 项 | 说明 |
| --- | --- |

| 课桌停车单（R） | 在自己座位上第一次按 R 先看停车单，之后 R 才是课堂题；危险、检查、选择框打开时不触发 |

## 原始验收记录

无窗口模式 **1031 项断言，0 失败**（新增 22 项）：停车单只读一次并记录、目标随进度推进、移交单四条记录与地图标点、第一天只读规则、补给只在对应地点出现且只能领一次、投币领药、背包满不领、拒绝后继续设施、关注与路线进度文字、搜索与最近发现、存读档与坏档、只记最近八条、牌号与车库一致；既有测试中 R 先读停车单、车辆查看与闸机错答事件顺序随之更新。截图 `pictures/调查笔记/`（`tools/capture/capture_notes.gd`）。**未验证**：窗口模式下 N 键与面板的实机操作（只验证了面板能打开）。

只是笔记与前置调查的界面与记录，没有新增结局或死法。「调查」不是新成就条目（旧版也没有），不需要新的 CG 或积分事实。无彩蛋内容。


## 横竖屏与字号

笔记主体独立滚动，记录文字和关注路线自动换行。搜索与关闭入口保留在屏内，四种窗口尺寸、85%／100%／150% 字号均有实际触屏关闭验证。新的合成长文截图由 `tools/capture/capture_documents.gd` 生成，只验证界面，不把测试记录当作玩家实际获得的线索。
