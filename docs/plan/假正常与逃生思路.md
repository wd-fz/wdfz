# 假正常与逃生思路

第一天熄灯时口袋里的纸条、第二天的「假正常」、以及按 H 打开的逃生思路。**规则照旧版**（`wd-fz/wd-fz.github.io@0bf508a` 的 `systems.js` FN_CHANCE 与纸条、`story.js` FN_EVENTS／fnTick、IDEAS／chooseIdea／trapWhere）。规则在 `features/story/fake_normal_module.gd` 与设施模块。
