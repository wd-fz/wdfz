# 其余画质档

旧版有五档画质（流畅、均衡、精细、超精细、真实），每档的模型与材质不同。Godot 版现在五档的建筑模型都有：设置里选哪一档，下次建世界（换场景）就用哪一档的模型；画质设置原有的渲染比例、抗锯齿与阴影照旧。玩法、布局与碰撞各档相同（只换视觉模型）。

## 内容

| 档 | 目录 | 大小（场景＋贴图） |
| --- | --- | --- |
| 0 流畅 | `assets/campus_q0/` | 约 70 MB |
| 1 均衡 | `assets/campus_q1/` | 约 135 MB |
| 2 精细（默认） | `assets/campus/scenes/` | 约 123 MB（原有） |
| 3 超精细 | `assets/campus_q3/` | 约 200 MB |
| 4 真实 | `assets/campus_q4/` | 约 320 MB |

每档都是 43 个场景（含楼梯井）。数据全部由旧版自己的建模函数导出（`tools/export_scenes/export_scenes.py --old <旧仓库> --quality N --out assets/campus_qN`），没有在 Godot 里另画。

## 机制

- `CampusData.scene_path(id)`：按 `CampusData.tier` 找 `res://assets/campus_q<N>/scenes/<id>.glb`，不存在回退默认档；`tiers_available()` 列出有数据的档。
- `game_app` 在应用设置时把 `quality` 写进 `CampusData.tier`；连廊／楼梯井／楼门／外廊的预览也按同一档取模型。
- 测试 `_test_model_tiers`：五档都在、每档每个房间有模型、楼梯井也有。

## 取舍

- 仓库因此多了约 800 MB（`.git` 约 400 MB 压缩后）。**Git LFS 在这个环境里被拒绝**（`lfs.github.com … Forbidden`），所以直接进了普通 git；要瘦身可以日后改 LFS（需要仓库开通）或改成运行时下载。
- 导出的第 4 档贴图是旧版「真实」档的原尺寸，运行内存与显存占用明显更高，低配机器不要选。
- 没有在每一档上逐场景截图比对（只截了第 0 档的 `teach1` 确认能加载与显示）。
