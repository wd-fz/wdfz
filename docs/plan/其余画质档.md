# 其余画质档

旧版有五档画质（流畅、均衡、精细、超精细、真实），每档的模型与材质不同；Godot 版目前只导入第 2 档（精细），画质设置只改渲染比例、抗锯齿和阴影（玩法与碰撞不变）。

## 已做的部分：切换机制

- `CampusData.scene_path(id)`：按设置里的画质档找模型，`res://assets/campus_q<N>/scenes/<id>.glb` 存在就用，不存在回退到默认档。所以各档可以一档一档、一个场景一个场景地加，不用再改代码。
- `CampusData.tier`：由 `game_app` 在应用设置时按 `quality` 写入，下次建世界（换场景）生效；`tiers_available()` 列出已导出的档。
- 导出：`python3 tools/export_scenes/export_scenes.py --old <旧仓库> --quality N --out assets/campus_qN [--only teach1,…]`。
- 测试 `_test_model_tiers`：默认档走原目录、没导出的档回退。

## 没做的部分：导出各档的数据（需要用户决定）

实测 `teach1` 一个场景：第 0 档 3.1 MB、第 2 档（现有）6.3 MB、第 4 档 14.2 MB（第 4 档贴图 19 MB，第 0 档 1.9 MB）。全部 87 个场景外推：现有第 2 档约 123 MB，第 4 档约 280 MB 另加贴图，第 0／1／3 档合计约 400 MB。全放进仓库会让克隆与 CI 都变得很重。可选做法：

1. 只导出第 0 档（流畅，约 60 MB），给低配与手机；
2. 各档用 Git LFS；
3. 各档做成运行时下载的资源包；
4. 不做，保持一档模型、画质档只调渲染。

在你选定之前，不往仓库里加这些大文件。
