# 背包丢弃

背包里每件物品多了「丢弃」按钮，**照旧版**（`wd-fz/wd-fz.github.io@0bf508a` 的 `items.js` `dropSelected`）：东西放下就没了，提示「我：我把「X」放下了。」，同时清掉快捷栏；手电筒会随之关掉。独有的门材料（线圈、透镜、试剂）丢弃后，可以回原处重新拿，免得误丢断掉整条路线。规则在 `game/features/items/inventory_module.gd` 的 `drop`，按钮在 `game/presentation/ui/game_ui.gd` 的 `show_bag`，接线在 `game/app/game_app.gd` 的 `_drop_item`（清掉 `FacilitiesModule.flags` 里对应的已取标记）。
