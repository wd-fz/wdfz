# 楼层草图地图

参考固定旧版 `wd-fz/wd-fz.github.io@0bf508a` 的 `exploration-map.js` 与 `ui.js:UI.renderMap`。状态统一见[计划目录](README.md)，运行证据见[迁移一致性验证](../迁移一致性验证.md)。

## 楼层草图

`ExplorationModule` 每 0.3 秒记录六格内视线能到的格子，墙和关门挡住后面的内容；虚空迷宫等 `noMap` 房间不显示地图。每层按六格一个字符压缩，保留走过与看见过的范围。原旧档由旧档导入边界转换；原生存档继续校验房间、字符与长度。

`MapView` 绘制纸色背景、淡格点、地面棋盘格、墙块和轮廓、已看清比例及当前位置与朝向。梯、电、廊、出、藏、台、机、服、书等文字代表看见过的陈设，不等于翻找过。留、锁、×、✓、开、车等动态标记由当前门、物品与路线状态决定。探索数量已经接入积分；记录回看保存当局草图。

打开所在楼层时，横向滚动定位到玩家，而不是停在左侧空白处。格子保留可读尺寸，过宽楼层可以横向滚动。切换楼层或关闭页面后，先前的延迟定位不能覆盖新页面；回主菜单关闭地图。

## 校园总图

`assets/campus/map.json` 直接导出原校园边界、道路、建筑与场地、全名与短名、三个校门。室外使用真实位置，室内标在所在建筑中心。

先画半透明道路与场地方块，再放名称。宽建筑内写全名；窄建筑使用原短名，按原候选位置与重叠代价避开已有文字和其他建筑。校门名称预留位置，避免被后放的建筑名称遮住。画布按可用宽高缩放并居中。

## 操作与尺寸

暂停页「地图」进入，选择校园总图或已走过的楼层；所在楼层注明「你在这里」。标题和图例换行，地图主体独立滚动，关闭按钮保留在屏内。横竖屏与 85%–150% 字号重新计算尺寸，长选项不把面板撑出屏幕；桌面点击与触屏共用关闭操作。

## 验证入口与边界

- `tools/export_reference.py --map-only` 在原浏览器里截取三组画布尺寸、道路矩形与文字坐标，形成独立对照样本。测试注入原字体测量比较名称避让算法；原生实际绘制使用当前字体的度量，不声称字体栅格逐像素一致。
- `tests/suites/campus_map.gd` 对照道路与名称、四种窗口尺寸及三档字号，检查总图居中、楼层滚动定位、图例与关闭可见、真实触屏关闭和返回菜单取消延迟定位。
- `tools/capture/capture_map.gd` 从正式新局截取总图与竖屏大字楼层页，保留真实探索遮罩，不虚构已探索区域。

受控窗口截图与触屏事件验证不能代替 Android 真机、自然长局及设备字体差异检查。
