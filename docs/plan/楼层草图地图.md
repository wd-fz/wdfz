# 楼层草图地图

手册的地图页，**照旧版**（`wd-fz/wd-fz.github.io@0bf508a` 的 `exploration-map.js` 与 `ui.js` 的 `renderMap`）：每层楼只画走过、看见过的格子；墙和关着的门挡住视线后面的格子；另有校园总图。规则在 `game/features/campus/exploration_module.gd`，绘制在 `game/presentation/ui/map_view.gd`，面板在 `game/presentation/ui/game_ui.gd` 的 `open_map`（暂停页「地图」按钮），接线在 `game/app/game_app.gd`（`_explore_step`、`_show_map`、`_map_label`）。

## 差异

- 旧版总图还画了道路（`ROADS`，几块半透明灰色）；这份数据没有从旧版导出，Godot 版总图不画道路。
- 总图上建筑名字用全名，旧版对窄建筑用短名（`o.s`），这份数据同样没有导出。

## 验收

无窗口模式 **1047 项断言，0 失败**（新增 16 项）：开局草图为空、6 格内被看见而远处没有、关着的门挡住教室而开着的能看到、百分比、六格一字符的压缩与还原、存读档与坏档、0.3 秒节拍、四种颜色与字母表。截图 `pictures/地图/`（`tools/capture/capture_map.gd`）。**未验证**：窗口模式下真实走动时的草图（截图里是把玩家逐点放到走廊上调用 `_explore_step` 得到的）；暂停页「地图」按钮的实机点击。
