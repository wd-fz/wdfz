# 结局分镜

旧版 `cutscene.js` 的 `CUT_DEF`（`wd-fz/wd-fz.github.io@0bf508a`）：每个结局先在场景里实时演一段（镜头、几样临时的东西、灯光与色彩），再出结局文字卡；演出时世界停住，点击／空格／回车／Esc 跳过。Godot 版的运行器是 `app/ending_cut.gd`（`EndingCut`），与开场共用淡黑与字幕层（`GameUI.cut_fade`／`cut_caption`）。

## 运行规则

- 只在有画面的运行里演（无窗口与测试直接出文字卡）；只在对应的场景里演（《白名单》要在校园户外）。
- 演完与跳过都走同一个出口：恢复暂停前的状态，再出结局卡；记录、积分、速通停表都在演出之前完成，跳过不改变任何结算。
- 没有声音的部分：闸机的「嘀」用 UI 点击声代替（旧版是 `SFX.click` 两下）。
