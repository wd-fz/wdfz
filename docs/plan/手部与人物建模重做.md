# 手部与人物建模重做

## 背景

本提案已由[建模与光影优化](建模与光影优化.md)接手。检查资产后确认第一人称手已经是连续皮肤、带指甲的雕刻模型；用户于 2026-11-10 确认保留。六种人形与巡察者采用圆润无脸造型，材质与日光一起调整。实现状态统一见 [README](README.md)。

以下保留原提案范围供对照；死亡 CG 的单独手、头等不纳入本次重建，不再将第一人称手描述为待重做的分段模型。

## 范围

| 原提案项 | 范围 | 处理结果 |
| --- | --- | --- |
| 第一人称手 | 左右手、袖口、手臂及三种握持姿势 | 经用户确认保留现有连续雕刻模型及挂点 |
| 人形 | 重做旧版六种人形（tall、roam、person、teacher、neck、sit）：比例、头、四肢、衣着；坐姿 `sit` 与课桌椅的配合；保持各自的身高与碰撞占位（`PAT_BODY` 等）不变 | 按后续建模与光影计划的确认范围实施 |
| 关联画面 | 死亡 CG 里的手、长脖子的头等（`assets/campus/fx`）、学生会检查队伍、巡察者模型（`patrol_figure.glb`）、结局分镜里的人群，换成新人形后逐处核对 | 按后续建模与光影计划的确认范围实施 |
| 画质档 | 新模型按五档画质给分段数（只改外形细节，不改玩法与碰撞） | 按后续建模与光影计划的确认范围实施 |

## 约束

- **玩法与建筑不变**：身高、体量、站位、可见范围、巡察者的视线与判定照旧；重做只换外观。
- 外观上需要偏离旧版造型的地方（比如面部、衣着），单独列出，经用户确认再改。
- 隐藏内容用到的人形（含隐藏结局、隐藏异象）只在内部材料里跟踪，不写进公开文档。
- 重做是新建模：建模方式（在 Godot 里程序化、或另做导出资产）与资产体量，开工前先给方案，经用户确认。

## 验收

- 近景对照截图（旧版导出 / 新模型），存 `pictures/手部与人物建模重做/` 并在索引加一行。
- 穿模检查：碰撞体与模型对照、可达性与卡位。
- 帧时间不明显回退（队伍与人群场景）；五档画质玩法一致。
- 测试：人形种类与身高、手的挂点与握持、各分镜里的人形替换不出错。
