# 手部与人物建模重做

## 背景

现在的手（`game/presentation/actors/hands_view.gd`）和人形（`game/presentation/world/campus/figure_model.gd`）都是旧版 `hands.js`、`figMesh` 的几何**原样导出**（`tools/export_scenes/export_scenes.py --only hands|figures`）：低多边形、顶点色，没有贴图，关节是分段的方块与圆柱。与恐怖设计原则要求的「校园日常的可信度」相比偏糙，近看（第一人称手、贴脸的同学、检查队伍、巡察者）尤其明显。本计划只管**重做模型**，不改玩法、判定、碰撞与位置。

## 范围

| 项 | 内容 | 状态 |
| --- | --- | --- |
| 第一人称手 | 重做左右手、袖口与手臂；手电、雨伞、手机的握持姿势与手指包裹；保持 `HAND_PLACE` 的挂点与摆动不变 | 未开始 |
| 人形 | 重做旧版六种人形（tall、roam、person、teacher、neck、sit）：比例、头、四肢、衣着；坐姿 `sit` 与课桌椅的配合；保持各自的身高与碰撞占位（`PAT_BODY` 等）不变 | 未开始 |
| 关联画面 | 死亡 CG 里的手、长脖子的头等（`assets/campus/fx`）、学生会检查队伍、巡察者模型（`patrol_figure.glb`）、结局分镜里的人群，换成新人形后逐处核对 | 未开始 |
| 画质档 | 新模型按五档画质给分段数（只改外形细节，不改玩法与碰撞） | 未开始 |

## 约束

- **玩法与建筑不变**（CLAUDE.md）：身高、体量、站位、可见范围、巡察者的视线与判定照旧；重做只换外观。
- 外观上需要偏离旧版造型的地方（比如面部、衣着），单独列出，经用户确认再改。
- 隐藏内容用到的人形（含隐藏结局、隐藏异象）只在内部材料里跟踪，不写进公开文档。
- 重做是新建模：建模方式（在 Godot 里程序化、或另做导出资产）与资产体量，开工前先给方案，经用户确认。

## 验收

- 近景对照截图（旧版导出 / 新模型），存 `pictures/手部与人物建模重做/` 并在索引加一行。
- 穿模检查（CLAUDE.md：更新了建模才做）：碰撞体与模型对照、可达性与卡位。
- 帧时间不明显回退（队伍与人群场景）；五档画质玩法一致。
- 测试：人形种类与身高、手的挂点与握持、各分镜里的人形替换不出错。
