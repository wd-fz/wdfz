# 正式校园建筑与碰撞

对应[分阶段迁移](Godot移植框架与分阶段迁移.md)的 M2 前半段：把旧版的教学楼、行政楼、实验楼、宿舍、食堂、钟楼等全部建筑与室外校园搬进 Godot，碰撞与出入口和旧版一致，能自然走进走出。课表、检查、跨日等时间规则属于 M2 后半段，另行实施。

## 约束

- **玩法与建筑都不能变**（用户 2026-11-06 指令）。几何一律由旧版自己的建模函数生成后导出，不在 Godot 里重画；碰撞矩形一律由旧版自己的碰撞数据算出。
- 参考基线：[wd-fz/wd-fz.github.io@`0bf508a`](https://github.com/wd-fz/wd-fz.github.io/tree/0bf508a47eac154c2a7047cdb45d314f61c48fdc)，与框架阶段相同。
- 接入现有框架：每个旧场景是一个 `WorldDefinition`，由 `WorldRouter` 切换；玩家仍是 `PlayerController`（CharacterBody3D）；不新增全局 Autoload。

## 后续（按依赖顺序，各自另建计划）

1. 楼梯井坡面与楼梯格出入、钟楼旋梯、电梯——打通全部楼层。**已在[楼层通行与校园日程](楼层通行与校园日程.md)完成。**
2. 灯光（`lighting.js`、`shade.js`）与门里门外互看（`campus-link/doors.js`、`gallery.js`），草地。
3. 时间与课表、座位、学生会检查——M2 后半段。**已在[楼层通行与校园日程](楼层通行与校园日程.md)完成。**
4. 玩家数值与背包（`domain/player-stats.js`、`inventory.js`、`items.js`）；随后才有钥匙开锁门。
5. 其余交互分支（`interact.js`）、巡察者、异象、剧情与结局（M3 起）。

## 不在本计划内

课表与时间规则、SAN 等数值、楼梯井与电梯、巡察者、异象、剧情与结局、音效、画质分档、草地等表现层装饰。它们在各自计划中移植；本计划只保证这些系统将来接入时，建筑、坐标与碰撞已经和旧版一致。
