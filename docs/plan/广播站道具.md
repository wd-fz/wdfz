# 广播站道具

参考固定旧版 `modules/broadcast/broadcast-view.js`。状态见[计划目录](README.md)，验证见[迁移一致性验证](../迁移一致性验证.md)。

## 广播站与线索

`BroadcastProps` 随房间世界搭建显示物件，碰撞来自房间配方。行政楼二楼的广播站门牌、功放、状态指示、话筒与格栅、播音记录本及保险丝状态牌使用原尺寸与文字。教导处文件柜、琴凳、保安岗登记簿、天台喇叭箱、通知档案钥匙与备用保险丝所在房间保留对应标签。

## 离校人群

`DepartingCrowd` 显示原 16 人双列队伍和背包，沿 `BroadcastModule.crowd()` 的时间与路径移动。前后间距、两列宽度、朝向、步行起伏均按原实现；侧列碰到校园障碍时退到中线。导出矩形有四位小数舍入，接触边缘时仅对显示查询留 0.1 毫米误差，不修改玩家碰撞体。

教室同学由 `ClassmatesView` 接收长铃状态后起身走向楼梯。铃停、换场景、重开与菜单不残留人群。人群掩护半径、长铃时长、出门与结局结算继续由广播规则模块负责，不由人形模型决定。

## 验证

既有道具测试核对所属房间、件数与保险丝状态。`tools/export_reference.py --classmates-only` 采集原队伍六个时刻的全部位置、朝向及起伏；`tests/suites/classroom_motion.gd` 使用真实室外物理复核侧列回退，同时验证五层教室离校与铃停恢复。截图入口 `tools/capture/capture_classmates.gd` 使用受控时间和机位。
