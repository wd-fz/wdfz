## 问题与修复（UDP 房间发现）

ENet 游戏流量（UDP 24560）已有四进程弱网、断线重连和 Terracotta 隧道的验证，这次检查后没有发现问题。出问题的是 `LanDiscovery` 的「查找附近房间」（UDP 24561）。在本机单进程里它能找到房间，但在真实网络中有以下问题：

1. **多网卡时找不到房间。** 查找请求只发往受限广播 255.255.255.255。Windows 上这个地址只从一块网卡发出，按路由选择，常常是 VPN、Hyper-V／VMware 虚拟网卡或虚拟组网网卡，连在真实 Wi-Fi 上的房主根本收不到。现在一次查找同时发往 255.255.255.255、每块本机 IPv4 网卡所在 /24 网段的定向广播（如 192.168.31.255），以及 127.0.0.1。回环地址用来发现同一台机器上的房间。
2. **Android 房主收不到查找请求。** 房主的发现套接字没有打开广播。Android 默认丢弃收到的广播包，要持有 Wi-Fi 组播锁才会交给应用，而 Godot 在套接字打开广播时才去拿这把锁，拿锁还需要 `CHANGE_WIFI_MULTICAST_STATE` 权限。现在两端套接字都打开广播，Android 两个导出预设都声明了这项权限，`tools/export_android.py` 也会检查 APK 里是否有它。
3. **同一房间重复出现。** 发到多个地址以后，同一个房间可能经回环和局域网各回一次。现在房间公告带一个随机 id（`room`，16 位十六进制），按 id 合并，优先保留其他玩家也能用的非回环地址。旧版本房主不带 id 时，仍按「地址:端口」区分。
4. **应答没有上限。** 房主对每个来源每秒最多应答 4 次，每秒最多应答 32 个不同来源，防止伪造来源的请求把房主变成放大器。
5. **查找过程没有反馈。** 原来查找 8 秒后静默停止，房间过期后列表会无声清空。现在查找持续 10 秒，按钮显示「正在查找…」并暂时禁用。结束后保留最后的列表（房间只在查找期间过期）。没找到时，面板列出排查要点：同一 Wi-Fi／路由器、访客网络和热点的设备隔离、防火墙放行 UDP 24560 与 24561、可以直接输入 IP。
6. 两端套接字绑定 IPv4 通配地址（`0.0.0.0`），不再用双栈地址，因为广播只存在于 IPv4。

不承诺的情况：大于 /24 的子网（如 /16 的校园网）里，跨 /24 的房间仍要靠受限广播或直接输入 IP；虚拟组网之间是否转发广播由组网工具决定。

## 加载画面

`game/presentation/ui/loading_screen.gd` 的外观改动如下。后台读取与处理模型的流程沿用[上一计划](菜单全景亮度、进入动画与开局加载.md)，没有改。

- 背景：雾气缓慢流动的暗墙（共用侧边菜单的 FBM 贴图），加颗粒与重暗角；挂钟背后有心跳暗红光。
- 中间是教室挂钟（新文件 `school_clock.gdshader`，与开机动画共用）。分针随进度从 17:00 走到 18:00，时针一起移动；红色秒针每秒走一格，带一点回弹。
- 标题「正在入梦…」加暗红描边。氛围短句从 4 句增加到 8 句，每 4.5 秒换一句，换句时先淡到无再淡入。
- 进度条：细血线，越靠近进度头越亮，头部有一颗会闪的余烬光点；未加载部分是一条暗淡的虚线。进度条下方左边写当前步骤，右边写百分比。
- 减少闪烁：心跳光固定不变，余烬不闪，颗粒不动，秒针不回弹；雾仍会慢慢移动。
- 节点名 `LoadingTitle`、`LoadingLine`、`LoadingStage`、`LoadingBar`、`LoadingBarBack` 都保留。`LoadingBar` 的长度仍等于已填充部分。新增 `LoadingClock` 与 `LoadingPercent`。

## 开机动画

`boot_splash.gd`＋`boot_splash.gdshader` 整体重写，主题从「血色裂缝」改为「傍晚六点的教室」。时长约 3.6 秒：

| 时刻（秒） | 画面 | 提示音 |
| --- | --- | --- |
| 0–0.25 | 全黑，颗粒 | |
| 0.25–0.9 | 墙顶日光灯启辉：亮、灭、半亮、暗，然后逐渐稳定；灯下照亮一片带污渍的灰墙和墙裙，灰尘在光里飘 | `world.lampFlicker` |
| 0.95–2.15 | 墙上挂钟从 17:59:52 开始，红色秒针每 0.15 秒走一格并带回弹；走到十二点时分针落到 12，挂钟显示 18:00 | |
| 1.35–2.6 | 「里世界」与「武汉大学附属中学」从模糊和噪点中浮现，标题下有心跳红光 | `threat.heartLow` |
| 2.5 | 秒针倒退一格回到 59，钟面泛红并轻微起伏 | `dread.knock` |
| 2.9–3.2 | 灯管闪几下后熄灭，留下一道暗红的灯丝余光；校名随灯光消失 | `world.lampFlicker` |
| 3.2–3.6 | 只剩标题的红色残影慢慢淡去，最后全黑 | |

结束时是全黑。主界面的「睁眼」进入动画本来就从黑暗中张开，所以不再像旧版那样先褪出菜单、再被眼睑重新盖黑。跳过（任意键、点击或触摸）改为 0.28 秒淡到黑。减少闪烁时总长 1.4 秒：灯光单调淡入、不闪烁，挂钟静止在 18:00，秒针不倒退，钟面不泛红，标题淡入后淡出到黑，不播放提示音。

`GameUI.play_boot` 不再传入菜单脊柱宽度，因为新动画不再从脊柱位置裂开。
