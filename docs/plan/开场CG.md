# 开场 CG

参考固定旧版 `opening.js` 与 `CUT_DEF.opening`。状态见[计划目录](README.md)，当前运行证据见[迁移一致性验证](../迁移一致性验证.md)。实现入口 `game/presentation/cinematics/opening_cut.gd`。

## 演出与交接

新局在正式教学楼教室演出六段：后排过道向讲台移动、老师重复念课文、粉笔灰停住、趴到桌上与黑场、第一人称醒来、交还控制。完整版 26 秒；看过一次后使用从第四段开始的 11 秒短版。无窗口测试或缺少正式教学楼时使用文字前情提要。

点击、空格、回车与 Esc 跳过；完成和跳过共用交接，速通从同一可操作边界起表。演出期间暂停游戏规则，不扣 SAN、不生成异象、不写途中存档。取消、重开、读档与菜单清理专用相机和回调。

## 人物、光照与声音

- 开始前先构建实际排座的同学。部分写字、部分翻页，其余不动；粉笔灰停住时动作定格，醒来时坐直。独立舞台重播使用自己的同学，不读取或修改正在玩的会话。
- 老师位于讲台与黑板之间。演出老师出现时隐藏正式老师，结束或取消时恢复，避免叠在一起。
- 正常世界灯光与画面调色按剧情褪去；同学和老师从原受光材质切成不受光黑影。早期“没有基准调色”的备注已失效，不再作为迁移限制。
- 原时间点的电流、闭眼与醒来声已接入；实际听感仍需单独验收。

## 验证

基础测试覆盖时长、短版起点、字幕与缓动；同学专项覆盖真实新局构建顺序、实际材质切换、老师显示与取消后的会话不变。完整窗口与档案重播继续验证跨场景生命周期。实拍 `tools/capture/capture_classmates.gd` 注入演出时间与机位，不能代替自然连续游玩或人耳试听。
