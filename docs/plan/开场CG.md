# 开场 CG

## 正常的教室

从主菜单创建新局，镜头位于本人的课桌前，教室灯光和师生均处于正常状态。监考老师发卷，学生签名、答题、交卷。玩家可以在这间教室停留直到提交。考试与醒来后的课表各自计时。[试卷规则与首章](替我答到.md)

## 睡着与醒来

收起成绩页后，镜头看到所选角色趴在桌上，闭眼变黑。从黑场抬头时切回第一人称，调色、老师和同学的姿态一起变化。交还控制后，角色低头就能读名牌。速通从这里起表。提前快进仍会经过醒来的画面。

联机的睡醒演出在每台设备独立播放。已醒来的玩家看到等候提示，全队完成后才开始共享校园模拟。档案里的重播独立运行，重看不会出题、发放奖励或修改答卷。
