# 开场 CG

旧版 `opening.js` 与 `CUT_DEF.opening`（`wd-fz/wd-fz.github.io@0bf508a`）：新局在真正的第一节教室里实时演一段，再把镜头原样交给玩家。`game/presentation/cinematics/opening_cut.gd`（`OpeningCut`）。
