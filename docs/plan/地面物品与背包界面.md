# 地面物品与背包界面

用户 2026-11-11 指令：「物品掉落应该在地上显示，并可以按 E 拾取，优化背包 UI 以及整体 UI 设计」。

这是对旧版玩法的**用户明确要求的改动**：旧版（`wd-fz/wd-fz.github.io@0bf508a` 的 `items.js` `dropSelected`）丢弃后物品直接消失；本轮改为放在脚边的地上，可以回来按交互键（默认 E，触屏为交互按钮）捡回。其余数值、规则与触发条件不变。

## 设计约束

- 落点：玩家脚下向前 0.28 米（小于身体半径，不会落进墙里）；特殊空间（迷宫、梦、电梯轿厢、驾驶中）仍按旧版直接放下即消失，避免物品落进不可回到的地方。
- 门材料（线圈、透镜、试剂）原有「丢了可回原处重取」保留，地上那份仍可捡回；从地上捡回会重新记为「已取」，已带着一份时提示并留在原地。
- 丢弃时先交给原有的路线判定；被判定接走的东西不会落在地上（具体规则不在此写）。
- 恐怖设计：地上物品用低调的实物样式与微弱轮廓，保证暗处可辨认，但不发出强光，不做悬浮旋转的游戏化图标。
