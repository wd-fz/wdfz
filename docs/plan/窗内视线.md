# 窗内视线

普通模式的本体异象「窗户内的视线」。**规则照旧版**（`wd-fz/wd-fz.github.io@0bf508a` 的 `modules/window-gaze/gaze.js` WG）。规则在 `game/features/story/window_gaze_module.gd`。

## 待办与进度

| 项 | 状态 | 说明 |
| --- | --- | --- |
| 窗的位置 | 已完成 | 只在行政楼、实验楼、宿舍、食堂、保安岗、器材室的外墙窗上（与旧版开窗规则一致） |
| 调度 | 已完成 | 运行 240 秒后才可能出现，之后每 300–480 秒；遇到异象、躲藏、学生会检查、追逐就往后排；持续 28 秒或离开这间屋结束 |
| 接触与吸住 | 已完成 | 2–18 米、夹角 12° 内、中间无墙（门、高柜、床也挡）盯 0.35 秒被吸住：视角被往窗口拉（限幅）、SAN 每秒 −2，2 秒后 −4（校庆减半） |
| 脱离与死亡 | 已完成 | 低头 35° 或偏开 28° 持续 0.6 秒、或被挡住即断开；SAN 被耗尽是「窗户内的视线」死亡 |
| 画面与声音 | 原人物、眼睛与专属演出已接入 | `WindowGazeView` 使用原尺寸人形，按南北外墙朝向室内；扁椭球眼睛跟随玩家，原无雾材质。呼吸声与声音字幕、七秒 `window_gaze` 死亡演出已有接线。 |

## 验收

两种模式各 **834 项断言，0 失败**（新增 9 项）：教学楼没有、其他楼有可用的窗、前 240 秒不出现、呼吸声前兆、直视被吸住、拉视角与扣 SAN、低头脱离、耗尽致死。
