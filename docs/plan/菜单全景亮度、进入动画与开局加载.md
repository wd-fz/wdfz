## 性能对照（Xvfb＋Lavapipe 软件 Vulkan，同一机器，只看相对变化）

从选好天赋到开局完成（`start_new_game`，开局教室 teach1）：

| 方式 | 总耗时 | 最长单帧（画面冻结） |
| --- | --- | --- |
| 改前：同步 | 约 6.2 秒 | 约 6.2 秒（整段冻结） |
| 只把读盘放到后台 | 约 8.7 秒 | 约 5.1 秒 |
| 读盘＋模型处理都在后台（当前） | 约 10.8 秒 | 约 0.76 秒 |

总耗时变长，是因为工作线程向渲染服务器取网格数据要和主线程同步；换来的是加载画面始终在动、有进度。剩下的约 0.76 秒是开局教室本体模型（`_build_model`）与会话安装，仍在主线程，发生在加载画面写着「布置教室」时。真机 GPU 与 CPU 上的绝对数值另需实测。
