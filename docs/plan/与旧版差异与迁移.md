# 与旧版差异与迁移

以 `wd-fz/wd-fz.github.io@0bf508a` 的实际游玩体验为基准，迁移到当前 Godot 项目。既保留规则、时序、碰撞、输入与存档边界，也复核画面、声音及事件可读性。用户已授权继续迁移；Claude 专用约定不构成 Codex 的开工或验收条件。计划状态统一见[计划目录](README.md)。

原清单中的「人物全是胶囊」「没有手部、开场、结局和声音」「音频尚未接线」已经过时。相关实现现已存在，不能继续把它们当作待从零编写的模块，也不能仅凭存在就宣布与旧版完全一致。以下以源码复核和运行对照为依据。

## 验收方式

1. 固定旧版源码 tree，直接运行原实现生成规则样本，避免让移植代码自己生成期望值。
2. 平面地图使用实际物理体对照；楼梯、旋梯、特殊空间使用真实角色跨门、上坡、落地和返回测试。
3. 事件分别验证触发、规避、结算、离开场景、读档及重开。画面和声音必须与同一份规则状态一致。
4. 验证桌面鼠标、触屏、暂停、设置、调试及过场交接；视觉效果不得改变保存的输入方向与玩家位置。
5. 运行无窗口、窗口完整回归，再用实际截图／录像核对。自动化没有覆盖的自然长局、随机组合与真机差异明确记录。

每批工作提交实现、必要回归和证据。已有检查通过后不无理由重复跑；新增模块、生命周期改动或新发现的问题需要重新验证。当前证据见[迁移一致性验证](../迁移一致性验证.md)，早期阶段记录保留在[正式校园验证记录](../正式校园验证记录.md)，其中旧日期的缺口不是当前状态。

## 已落实的第一批整改

- 预览模型沿连接门槛裁切，消除覆盖当前通道的单面假墙，保留原实墙碰撞。
- 预览门状态同步及旧版 12／15 米显示范围；教学楼天台楼梯开口深度修正。
- 原运行时的 34 个普通场景、55,954 个碰撞样本与 2,126 个时间样本加入回归。
- 镜头运动加入 360 帧原实现对照；坐姿、奔跑、受伤、读档状态独立管理。
- 蛾群由实际暴露量驱动，音量随可见群体距离变化，屋檐遮挡接入雨声。
- 当前场景即时切换画质，保持物理体、门、玩家与运行中事件；恢复原粒子数量和精细档太阳阴影。

这批通过不代表整个移植完成。上述剩余范围需要逐项关闭并给出证据，尤其不能用普通房间的平面碰撞对照代替分层特殊空间的可玩性验证。
