# 与旧版差异与迁移

2026-11-07 按用户指令，对照旧版（`wd-fz/wd-fz.github.io@0bf508a` 的 `game3d/js/`，203 个源文件）逐项列出 Godot 版**仍与旧版不一致**的地方，并排出迁移顺序。

核对方法有两种：
- **源文件核对**：逐个检查旧版源文件，看移植代码与文档里有没有引用；没被引用的约 100 个，逐个读文件头说明归类。引擎、适配层与建模配方（由 `tools/export_scenes/` 导出）不算差异。
- **计划文档核对**：汇总各计划文档里记下的「占位／未移植／近似／例外」，用当前代码复核。已经补上的从清单里去掉，例如天赋、请假条、到场责任、特殊日关闭、售货机、传送门隧道。

隐藏内容按 CLAUDE.md 最高保密规则，不在本表列名，只在内部材料里跟踪。

优先级沿用 CLAUDE.md 第 6 节：**P0** 不公平必死／信息不足／状态错误 → **P1** 声音与张力节奏、环境反馈 → **P2** 多样化 AI 与环境叙事 → **P3** 其余表现。移植期以「与旧版一致」为准，不借机改玩法；有意保留的差异要单独列出，经用户确认。
