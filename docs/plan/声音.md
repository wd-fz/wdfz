# 声音

旧版的音频与 `sensory/` 感官模块尚未移植；本轮用**合成占位音**（`app/audio_fx.gd`）补上「声音先行」的预兆层。仓库里没有音频文件，所有声音由数学函数生成并缓存。声音只读状态，不改变任何规则。

## 待办与进度

| 项 | 状态 | 说明 |
| --- | --- | --- |
| 合成音与播放器 | 已完成（占位） | 脚步、沉重脚步、心跳、闷响、钟声、车铃、水滴、门轴、广播杂音、预兆音、惊吓音、结局和弦，及室内嗡鸣、室外风、雨声三条循环 |

| 真实音效与配乐 | 未开始 | 需要音频资产；声音设置界面（分类音量）也未做 |

## 验收

两种模式各 455 项断言：全部 15 种合成音存在且有数据；环境音循环、一次性音不循环；未知音为空；走路出脚步、低 SAN 出心跳、巡察者 3D 脚步；室内嗡鸣与室外风／雨的切换、停电关嗡鸣；静音与取消静音作用于主总线；`stop_all` 停所有循环。**未验证**：听感（容器无声卡，只验证了生成与触发，没有人耳试听）、响度平衡、真机。

## 与旧版的已知差异

旧版的音效、配乐、广播语音、人声与空间音效没有移植；这里的声音只是预兆信号的占位，不应当作还原。
