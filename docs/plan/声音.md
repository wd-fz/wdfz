# 声音

旧版的音频与 `sensory/` 感官模块尚未移植；本轮用**合成占位音**（`app/audio_fx.gd`）补上「声音先行」的预兆层。仓库里没有音频文件，所有声音由数学函数生成并缓存。声音只读状态，不改变任何规则。

## 验收

两种模式各 455 项断言：全部 15 种合成音存在且有数据；环境音循环、一次性音不循环；未知音为空；走路出脚步、低 SAN 出心跳、巡察者 3D 脚步；室内嗡鸣与室外风／雨的切换、停电关嗡鸣；静音与取消静音作用于主总线；`stop_all` 停所有循环。**未验证**：听感（容器无声卡，只验证了生成与触发，没有人耳试听）、响度平衡、真机。

## 与旧版的已知差异

旧版的音效、配乐、广播语音、人声与空间音效没有移植；这里的声音只是预兆信号的占位，不应当作还原。

## 第二阶段：旧版音效与环境声（2026-11-07 起）

旧版没有音频文件：一次性音效是 `sound-bank.js` 里的 150 个合成配方，由 `fx/sound-player.js` 现场合成，响度按 `sound-levels.js` 校准；持续层（铺底、紧张层、风、雨、灯管嗡声、车库低频）在 `audio.js` 里用振荡器和滤波噪声实时生成。本阶段把它们**照原配方**搬进 Godot：

- `tools/audio_bake/bake.cjs` 在 Node 里直接加载旧版的 `sound-bank.js` 与 `sound-levels.js`（不改动、不转写），按 `sound-player.js` 的取值逻辑展开配方（范围随机、函数取值、重复、声像），用照 Web Audio 规范写的合成（指数包络与滑音、Web Audio 参数约定的 RBJ 双二阶滤波、等功率声像、AM／颤音／FM／共振峰）渲染，再乘旧版的响度校准，编码为 Ogg Vorbis 写进 `assets/audio/`。短音效烘三份、中等两份、长的一份；播放时再加配方的音高与响度浮动。持续层烘成无缝循环。
- 保密：隐藏内容的声音不烘焙（工具里的 `SKIP` 规则），不进资产与公开文档。
