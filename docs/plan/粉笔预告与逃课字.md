# 粉笔预告与逃课字

旧版 `fx/classroom.js`（`wd-fz/wd-fz.github.io@0bf508a`）的两种自己冒出来的粉笔字。`world/campus/chalk_notes.gd`（`ChalkNotes`），由 `game_app._chalk_step` 每帧驱动。

## 待办与进度

| 项 | 状态 | 说明 |
| --- | --- | --- |
| 异象预告 | 已完成 | 异象快来了（`AnomalyModule.warning_visible`）时，把它发生的钟点写在面前的墙上（教学楼教室的前墙就写在黑板上），六格内没有墙就写在前方两米的地上；字慢慢浮出来。这是预知梦难度的提示：看见后说「这个时间……我梦见过」（`warning_seen`，之前一直没有接，因为没有可看的字） |
| 逃课警告字 | 已完成 | 在不对的地方（`SchoolModule.wrong`）且违规 ≥ 12 时，每 `max(1, 5.6 − 0.048·违规)` 秒在身边地上或墙上冒一句（不要逃课／回去上课／这节是数学／老师在等你／点名了／你又迟到了／回去），最多 28 条，违规降到 8 以下或离开不对的地方就擦掉；学生会检查时不出 |
| 与旧版的差异 | — | 预告的数字旧版用七段线条一笔一笔拼出（`SEG_MAP`），这里是 `Label3D` 的字，没有逐笔浮现；逃课字旧版是手写体贴图（楷体、每字大小角度不同），这里是统一字号；黑板上的预告不做「限制在板面里」的位置夹取（板面前移 0.095 m 照旧） |
