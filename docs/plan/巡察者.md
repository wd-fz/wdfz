# 巡察者

全校唯一常驻的巡察者：连续步行、视线锁定、追逐与抓捕、躲储物柜、区域报警、挡电梯门，以及外出登记后缺席的永久追踪。**玩法照旧版**，参考基线 `wd-fz/wd-fz.github.io@0bf508a`；栅格、导航图、路线与区域表全部由旧版运行时导出，不在 Godot 里重新推导。

## 验收

`python tools/check.py` 与 `xvfb-run -a python tools/check.py --windowed` 各 309 项断言全部通过。巡察相关：数据与图规模、A\\* 连通、线段穿墙判断、最短路、两分钟巡逻会前进并跨场景、迎面走来的锁定（只开一次 +8 违规）与抓捕（grip／patrol）、坐在本人座位不被追、符纸烧毁并驱逐 30 秒、夜里室外才有资格、躲柜（没被看见不被搜、出柜位置）、永久追踪与救命清除、进入机房核心区只上报一次、存档往返；真实场景里躲柜与出柜、躲着不能走、人形出现与消失。截图在 `pictures/巡察者/`。

## 与旧版的已知差异（未移植，不是改动）

- 路径细节：栅格 A\\* 换成了 Godot 内置实现，同等代价的多条路线里选哪条可能和旧版不同；其余规则与数值相同。
- 无线破解暴露位置（`revealWireless`）：入口已写好，手机与网络系统移植时接上。
- 虚空迷宫网关、电梯里被追时的迷宫分支、顺风耳天赋、驾驶追逐、小刀与隐形钩子：对应系统尚未移植，按「没有」处理。
- 广播站报警区：广播站移植前不生效。
- 脚步声、门轴与灯管噼啪声：声音系统未移植。
- 请假条：未移植，`on_leave` 恒为否。
