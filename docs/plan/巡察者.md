# 巡察者

按 `wd-fz/wd-fz.github.io@0bf508a` 迁移全校唯一常驻的巡察者。计划状态统一见[计划目录](README.md)，分批运行结果见[迁移一致性验证](../迁移一致性验证.md)。

## 规则与边界

| 范围 | 旧版参考 | 迁移要求 |
| --- | --- | --- |
| 普通导航 | `modules/patrol-world/navigation.js` | 使用原 32 个场景的代理栅格、121 节点／128 边连接图、128 节点路线和 9 个报警区。整段检查、禁止挤角、显式楼梯／旋梯／跨场景连接；不得靠当前玩家所在房间猜测巡察位置。 |
| 分层特殊空间 | `navigation.js` 的 `maze` | 半米步长，脚高属于节点；体素、坡道与玩家物理场景共享来源。每段中点也验证支撑和碰撞，防止跨越断桥、薄墙和不允许的落差。 |
| 特殊空间入口 | `world.js` 的 `mazeRoute`、`leaveRoom` | 记录入场电梯楼栋与楼层；巡察到对应电梯口后用原两秒连接进入。返回经南侧出口回到原电梯口，再恢复校园路线。 |
| 行为与资格 | `world.js` | 保留巡逻、调查、追逐、搜查与归队优先级。锁定／丢失／搜索、安全期、抓捕距离与室外长距离赶路规则照旧；夜间追室外，坐在本人座位、请假和非夜间外出登记照原规则豁免。 |
| 躲柜与电梯门 | `patrol.js`、`world.js` | 目击躲柜会记住位置；门前赶到会扒开电梯门，成功关门则留在外面搜查。躲藏、开门、保护与抓捕只结算一次。 |
| 到场责任与永久追踪 | `attendance.js`、`school-day.js` | 缺席责任导致永久追踪，续签和假条不解除。无线报点保留当时静态位置；跟随、区域报警和广播源通过模块边界接入。 |
| 表现 | `engine/presentation.js`、`lighting.js` | 人形、步声、方向／遮挡、灯光节拍和红光只读取同一巡察状态，不能靠视觉瞬移代替普通移动。顺风耳、驾驶、伪装和小刀由对应系统协作。 |
| 存档 | `world.js` persistent | 保留脚高、入口、追踪策略和进行中的连接剩余时间。分层空间无支撑或嵌墙的落点按旧规则回固定安全出生，不能把有效深层位置一律重置到校园。 |

## 验证

以原 Web 运行时生成路径、视线、跨场景时间轴与存档样本；验证两个出口、坡道、返回连接和读档接续。普通平面导航使用 Godot `AStarGrid2D`，同等代价路径的选择可能与旧版堆实现不同；特殊空间按原半米搜索与中点判定实现。

除纯规则对照外，使用实际场景碰撞验证巡察路径，运行校园、躲藏、门前追逐、保护与死亡回归。早期 309 项验收记录保留为历史证据，不代表当前覆盖数量；当前数量和限制以统一验证记录为准。
