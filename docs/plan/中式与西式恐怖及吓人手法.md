## 一、调研

### 1. 中式恐怖

| 特点 | 说明 | 例子 |
| --- | --- | --- |
| 诡异重于惊吓 | 常见的概括是：西式重视觉冲击与「惊悚」，中式重气氛渲染与「细思极恐」。最让人发毛的，常常是说不清哪里不对的旧习俗和规矩，而不是血腥 | 《纸嫁衣》《烟火》《喜丧》（后者几乎没有鬼的形象） |
| 民俗符号 | 纸人、红嫁衣、冥婚、棺材、符咒、纸钱、七月半等。危险在于把它们只当布景（研究者称之为民俗「景观化」），没有让它们参与叙事和玩法 | 《纸人》《纸嫁衣》系列被举为景观化的例子 |
| 仪式即玩法 | 点蜡烛、折元宝、烧纸钱既是解谜步骤，也在铺气氛，玩家亲手做的事本身就带有禁忌感 | 《烟火》 |
| 熟悉的环境 | 在国人熟悉的日常环境里制造「哪里不对」：老小区、筒子楼、山村、学校 | 《还愿》的 1980 年代台北公寓 |
| 人比鬼可怕 | 鬼怪常是社会创伤、家庭压迫与集体记忆的投影，最后往往指向人性。批评意见是：反复以女性受难、冥婚、家暴为卖点，会变成消费苦难 | 《烟火》《返校》《还愿》；对《港诡实录》中女鬼身世只作背景的批评 |
| 间接表现 | 有研究指出，受审查限制，中国开发者常用间接手法（幻境、人为机关、梦）代替直接的鬼怪，这反而形成了自己的特色；也有作品坚持「真有鬼」的路线 | DiGRA 关于中国恐怖游戏「快感机制」的论文 |
| 规则怪谈 | 2021 年前后在中文网络走红的体裁（常以「动物园规则怪谈」为标志）。它利用人们对「规则 = 权威 = 安全」的信任，在规则里掺入异常和互相矛盾的条目：异常成为新的日常，规则变得不可靠。恐惧从肉体转向观念（秩序与混乱）。形式上像说明书或守则，读起来就像在玩游戏 | 本作的核心体裁 |

### 2. 西式恐怖

| 特点 | 说明 | 例子 |
| --- | --- | --- |
| 解释与对抗 | 红烛游戏与 Bloober Team 的对谈说，西式恐怖倾向于把一切讲清楚，情节更「科学」；传统上玩家常有武器可以对抗怪物 | 《生化危机》系列 |
| 生存恐怖 | 资源稀缺（弹药、存档、药）让人一直担心不够用；「生存恐怖」一词来自 1996 年的《生化危机》 | 《生化危机》《死亡空间》 |
| 子类型 | 宇宙恐怖（人类在不可知力量前渺小）、身体恐怖（变异、感染、身体不自然地运动）、砍杀（追杀者）、心理恐怖（让人怀疑自己看到的是不是真的） | 《寂静岭》被视为早期心理恐怖游戏 |
| 无力与想象 | Frictional（《失忆症》）认为恐怖的大部分发生在玩家脑中：不给武器，用安静的空间和声音喂养想象；身体上的不适太多反而会打破沉浸 | 《失忆症：黑暗后裔》 |
| 熟悉空间的循环 | P.T. 让玩家在同一条走廊里反复走，每走一圈都有细微变化。这是弗洛伊德说的「恐惑」（熟悉之物变得陌生）。玩家找不到规律，信心就建立不起来 | P.T.、《生化危机7》 |
| 阈限空间 | 空的商场、学校、走廊让人不安：它们本该有人，大脑认得这个场所，却无法接受它空无一人。卡迪夫大学 2022 年的研究把这种不安与「恐怖谷」效应联系起来 | Backrooms |
| 系统化的威胁 | 《异形：隔离》用双层 AI：导演层知道玩家在哪、管理紧张度（「威胁计量」），异形本身只能靠感官去找。这样既有节奏，又不会让玩家觉得被系统作弊 | 《异形：隔离》（GDC 2015「Building Fear in Alien: Isolation」） |

### 3. 日式对照（中、西之间的参照）

《零》系列制作者说，日式恐怖少用跳吓和血腥，节奏慢，基调更哀伤、更个人；怨灵常被同情而不只是敌人。核心机制（用相机对付鬼）逼玩家「直视可怕的东西」。研究也提醒，早期《生化危机》《寂静岭》本就吸收了大量西方恐怖元素，影响是双向的，「东方 / 西方」只是粗略的划分。

### 4. 恐怖游戏怎样才吓人（共识）

1. **紧张比惊吓重要。** 《寂静岭f》在 GDC 上的分享把恐怖定义为每时每刻的玩法紧张；「可能会被吓」往往比真被吓更紧张。
2. **蓄力—释放—喘息。** 只蓄不放，恐惧会钝化；要有释放和安静的喘息，再重新蓄起来。
3. **节奏不能被背下来。** Glen Schofield：每五分钟准时吓一次，玩家就会去等下一次；要打乱节奏，允许长时间的安静和落空的威胁。
4. **背叛安全感。** 《FAITH》的作者建议找到玩家认为安全的地方，再背叛这份信任。但要留前兆和退路（这与 CLAUDE.md「不把安全区无预兆变成陷阱」一致）。
5. **留给想象。** 看不见的东西最可怕：先听到再看到，半掩的门，暗处；画面越少，想象越多。
6. **声音先行。** 《死亡空间》给物体和敌人挂「恐惧发射器」，实时混合多层音乐；《寂静岭》的山冈晃刻意让混音不可预测，有时在大惊吓时把声音全部切掉；收音机的杂音成了怪物将至的信号。完全的静音会显得空洞，要留底噪。
7. **吓人，但别折磨。** 《Saturnalia》：遭遇少而精，让玩家害怕而不是受折磨；时机对了就能躲开。
8. **恐惧有最佳区间。** 奥胡斯大学的「娱乐性恐惧实验室」在鬼屋实测到倒 U 形：太少不够刺激，太多不再好玩；不确定性是核心，玩家对不确定性的承受力各不相同。
9. **熟悉的地方变得不可信。** 恐惑、阈限空间与 P.T. 的循环都说明：最好的恐怖舞台，往往是玩家最熟悉的日常空间。

### 5. 对本作的启示

本作恰好处在几条线的交汇处：**校园**是最熟悉的日常空间（恐惑、阈限空间）；**规则怪谈**是中式网络恐怖的代表体裁（规则、权威与矛盾）；**巡察者**是系统化的威胁（双层 AI）。由此得出三条方向：

- **中式之魂**：让规则、课表、广播、值日表这类校园里的「权威文本」逐渐变得不可靠，诡异来自日常秩序的细微错位，而不是血和跳吓。
- **西式之骨**：用系统撑起紧张：声音先行的威胁、导演层控制的节奏、可推理的追踪 AI、可归因的失败。
- **避开的坑**：民俗只当布景（景观化）；消费女性苦难；无提示秒杀；可以背下来的定时惊吓；把全部安全区变成陷阱。
