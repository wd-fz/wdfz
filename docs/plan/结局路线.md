## 验收

`python tools/check.py` 与 `xvfb-run -a python tools/check.py --windowed` 各 **406 项断言，0 失败**。路线相关：实验楼终端无 U 盘只给提示、其他终端不联网、未写入时数据机提示；写入后 5.2 秒提醒、同步与重复同步；三个校门位置与台词；答题三问、答错扣 SAN 与换题、三道答完开门、走出即结局；路线状态 JSON 往返；垃圾房垃圾桶死法；一局只结束一次。应用层用真实交互走完整条路线（在终端旁按 E、在西小门按 E、点选择、结局卡显示、存档清除、结局记录、返回菜单）。截图 `pictures/结局路线/`。

截图里发现并修复：居中的选择框、背包、死亡卡和结局卡原先向右下生长而被屏幕裁切，现改为向四周生长居中。
