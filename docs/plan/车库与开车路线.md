# 车库与开车路线

车库里的黑影、硬币诱饵、找车试钥匙、开车逃离与《闸门》结局沿用旧版路线。单人和合作的规则共用 `GarageModule` 与 `CarChaseRules`，画面由 `CarChaseView` 和 `CampusWorld` 绘制。

## 验收

两种模式各 **543 项断言，0 失败**（新增 36 项）：车位与车牌、黑影出现与靠近、手电照退与重新出现、黑暗中碰到的死法与进门保护、硬币诱饵与在别处不扔、没钥匙锁着、黑影在旁时开门的死法、试钥匙读条与走开松手、错车记忆与不重试、对的车开始驾驶、状态 JSON 往返与非法车位拒绝、驾驶规则（停车追兵、撞路障、岔路走错退回、检查点、通过）；应用层：车的提示显示车牌、钥匙说明车牌、按 E 选择试钥匙、读条后上路、校园隐藏、开出去得到《闸门》结局卡与成就。截图 `pictures/车库与开车/`。

新接入的旧版内容：成就「照亮」「一次就对」「《闸门》」；死亡档案「车道中间」「后座」「没开出去」与结局《闸门》；死因说明与复盘提示照旧版。没有新增玩法或彩蛋内容。

## 与旧版的已知差异

- 停车登记（保安岗）与调查笔记未移植：玩家只能靠钥匙上的车牌找车。
- 速通、记录、开车过场与旧版道路画面未移植。
- 未验证：自然游玩中车库的难度（黑影速度、手电读条）与驾驶手感；真机。
