# 车库与开车路线

车库里的黑影、硬币诱饵、找车试钥匙、开车逃离与《闸门》结局。**玩法照旧版**（`wd-fz/wd-fz.github.io@0bf508a`）：`systems.js` 的 ROAM（车道上的东西）、`items.js` 的 throwCoin、`story.js` 的 carRightCell／useCar／carDrive、`investigation.js` 的车牌、`car-chase.js` 与 `domain/car-chase.js` 的驾驶规则。规则在 `game/features/garage/`（`GarageModule`、`CarChaseRules`），画面在 `game/presentation/world/campus/car_chase_view.gd` 与 `CampusWorld.show_garage_shadow`。

## 验收

两种模式各 **543 项断言，0 失败**（新增 36 项）：车位与车牌、黑影出现与靠近、手电照退与重新出现、黑暗中碰到的死法与进门保护、硬币诱饵与在别处不扔、没钥匙锁着、黑影在旁时开门的死法、试钥匙读条与走开松手、错车记忆与不重试、对的车开始驾驶、状态 JSON 往返与非法车位拒绝、驾驶规则（停车追兵、撞路障、岔路走错退回、检查点、通过）；应用层：车的提示显示车牌、钥匙说明车牌、按 E 选择试钥匙、读条后上路、校园隐藏、开出去得到《闸门》结局卡与成就。截图 `pictures/车库与开车/`。
