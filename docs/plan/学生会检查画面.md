# 学生会检查画面

旧版 `fx/inspection-fx.js`（`wd-fz/wd-fz.github.io@0bf508a`）：检查开始时，玩家身边站出至多六个黑色的人形；检查结束（结算后）它们不是凭空消失，而是在 0.8 秒里朝远离玩家的方向走开（1.5 m/s），同时淡出。

## 验收

`tests/suites/world_people.gd` 对照原运行时的点位、模型与四个消散时刻，覆盖检查期间玩家移动后的方向、透明度及 0.8 秒释放。`_test_inspection_scatter` 保留无检查时的基础断言。检查黑影按原设计是纯视觉节点。截图与统计见[迁移一致性验证](../迁移一致性验证.md)。
