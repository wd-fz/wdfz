# 局域网合作

v0.3.0 起支持合作模式。当前在主菜单的「新的轮回」中选择「与好友联机 · 2–4 人」，再选「同一 Wi-Fi / 热点」。由一台设备担任房主并运行世界模拟，其他设备连接它。无需云服务器或账号；没有公网匹配、中继和房主迁移。v0.2.x 不含此功能，所有成员需更新到相同构建。

异地好友在同一面板切换到[远程联机](远程合作.md)，通过邀请码加入；本页仍描述同一局域网或已经互通的虚拟局域网中的直接连接。

## 建房与加入

1. 所有人使用相同构建。联机会核对协议、规则和内容指纹，混用不同代码版本会被拒绝。
2. 房主选择「创建房间」，默认四人、普通难度，可勾选「规则怪谈」后点击「创建并等待好友」。无需填写表单；称呼、房间名及端口在「设置」中，默认游戏端口为 **UDP 24560**。有存档时显示「继续上次合作」。规则怪谈的启用状态在大厅展示，准备即接受本局规则，恢复存档沿用原选择。
3. 好友选择「加入房间」，自动查找附近房间，**点房间即加入**。发现使用 **UDP 24561**，持续约 10 秒；可以刷新。当前版本会标出版本不同、房间已满或进行中的房间。
4. 找不到时展开「直接连接」，粘贴房主地址。房主在「连接帮助」中复制连接地址；多网卡时选择实际连接路由器或热点的网卡。不要把 `127.0.0.1` 发给另一台设备。广播发现失败不影响直接连接。
5. 每人选择天赋并准备，房主开始。至少两人，最多四人。世界在成员完成加载后才开始计时；无法加载的成员可由房主移除，但开局仍需至少两人。

Windows 防火墙应允许本程序在当前可信网络上收发 UDP；Linux 防火墙应放行所用游戏端口，发现功能另外需要 24561。电脑装有 VPN、虚拟机或虚拟组网网卡时，查找会同时发往每块网卡所在的 /24 网段；子网更大或更特殊的网络仍以直接输入 IP 为准。Android 房主需要系统授予的「Wi-Fi 组播」权限（安装时自动声明）才能收到查找请求。热点和访客 Wi-Fi 可能禁止设备互访；这时检查路由器的客户端隔离，或换普通局域网。虚拟组网若提供互通的 IPv4，可尝试直接输入地址，广播发现不保证跨虚拟网络可用。

加入过程中显示「连接房主 → 校验版本 → 进入房间」，期间不能反复发起加入，可用固定底栏取消。发现端口能通信不代表游戏端口一定能通信；超时会区分设备未连接与房间未确认。需要进一步排查时，两端都可在「连接帮助」复制诊断信息，里面记录连接阶段及握手事件，不含邀请码或重连凭据。触屏列表刷新吞点击的修复、验证范围见[联机入口与连接排查](联机入口与连接排查.md)。

Android 两个导出预设均声明 `INTERNET`，APK 验证脚本检查最终清单。Android 仍为横屏、强制全屏；桌面默认窗口化，Linux 原生 Wayland 的配置保留。手机进入后台可能被系统暂停或终止，因此房主应保持应用在前台。

Linux Wayland 在后台完成加载或重连时，会保持光标可见；切回游戏后单击画面，即可重新捕获鼠标控制视角。

## 合作规则

日历、检查、巡察者、车库黑影、门、电梯、设施冷却、容器、地面物品、路线和调查知识属于全队。SAN、违规、同化、体力、天赋、背包、座位、生死、小游戏和隐藏经历属于每个成员。手机电量、联网及下载进度属于手机实例，交给队友或丢下再捡回时随手机移动；服务器停机任务属于世界。一天仍按现有约 20 分钟的自然日规则推进，逐日压力不会乘以人数。

- 每人有独立的本人座位，可分开探索不同楼层；普通校园使用连续空间，能透过真实门洞看到邻区队友和巡察者。队友身体不互相推挤，座位、柜子、电梯操作席和驾驶位仍检查占用；空着的队友座位可以坐，但不算自己的课位。手机只能在自己的原教室充电。
- 「队伍」中选择背包物品，再点某位队友的「交付物品」。需在连续校园的两米内、无遮挡且对方能收下，可隔着打开的区域接缝交付。物品按唯一实例转移，两人争抢只结算一次；包扎途中转交或丢弃急救包会取消治疗。
- 最终死亡或正式离队时，物品留在原地点。个人迷宫／梦境消失时，物品回到其校园入口所在楼层或入梦地点，避免困在无法访问的副本。地面容量已满时进入保护队列，有位置后重新落地；材料留在背包、地面或保护队列时不能再从来源处重复领取。
- 巡察者全校只有一个。违规档位、永久追踪、躲藏和报点归属于本人；无线破解每 15 秒留下当时的静态位置。夜间普通归寝豁免不清除个人另行触发的责任。
- 个人背包、设置、手机、读书和暂停页只停止本人的操作，世界继续运行。房主可在队伍窗口发起最长 120 秒的全队暂停，任一在线成员可恢复。
- 会推进日历的休息和设施活动需要存活成员同意；支付、奖励和时间在确认后一起结算。课堂整理同样需要同意，但运行完整世界模拟的六倍速；队友移动、遇险或本人再次按课堂键时恢复正常速度。取消、离开设施或遇险不会提前领取奖励。吃药等不跳时行为仍独立结算。
- 电梯只移动实际进入轿厢的人；队友站在门口会阻止关门。先完成车辆钥匙／接线任务，再由所有存活成员靠近并确认后开始驾驶；司机掉线时由在线乘客接手，没有可接手者则取消本次驾驶。车库只有一个黑影，能被任一有视线的队友用灯照退，距离伤害分别结算。
- 安全躲柜仍有 45 秒敲击、55 秒呼吸、65 秒推出并扣 4 SAN 的个人计时；正在被追逐、柜子被搜查或自己听得到巡察者靠近时暂停，队友别处的危险不会串到本人。
- 个人救助和预知梦沿用现有规则，不重置队友进度。最终死亡后可以跟随存活队友观战。房主死亡仍继续提供服务；没有新增队友无限复活。

## 六条公开结局

| 路线 | 合作方式与最后条件 |
| --- | --- |
| 白名单 | 网络中心、数据同步和闸机验证共用进度，可以分工；存活队友在闸机附近集合并确认。 |
| 闸门 | 一辆车、一名司机，其他成员确认乘车；共同完成追逐距离和分叉，最后确认结算。 |
| 门 | 图纸与建造进度共享，材料交给实际组装者；队友靠近已建成的门，各自确认进入后共同结算。 |
| 放学 | 通知稿、广播与长铃共用，操作者可和探索者分工；最后每名存活成员都要处在人群遮掩范围，不能由一人替远处队友通关。 |
| 网安仙人 | 终端席位互斥，已提交的服务器任务属于全队；倒计时不会随最初操作者死亡或退出终端而停止，存活成员确认结算。 |
| 外国语学生 | 共享语言验证、接待与行进路线；逐人计算掉队和搜索者威胁，所有参与逃离者需跟上队伍到终点。 |

一局只结算一个共同结局。暂时断线的存活成员在保留期内仍需返回确认；房主也可明确移除。最终确认会重新检查位置和生死，提前确认后走远不能远程通关。死亡成员保留自己的死亡结果，同时记录全队结局。

## 个人活动与隐藏内容

手机纸飞机和机房贪吃蛇由房主运行规则，客户端只发送点击／转向，不能上传分数领奖；进入小游戏不暂停队友。奖励、冷却与进行中状态随合作存档恢复。相机照片和相册只存本机，不随快照发送；闪光引起巡察者注意仍由房主按距离和实际遮挡判断。电量耗尽、检查或遇险会自动收起手机。

隐藏路线由个人探索，真正逃离仍须全体存活成员同意。《先辈》接入真实丢弃与隔间交互；《盗梦空间》从宿舍睡眠、陀螺判定到出口；《管制刀具》作为个人假结局记录，收走小刀后只让本人回自己的座位，不推进全队日期、不结束队友游戏。个人迷宫和梦境各有独立物理空间、返程位置与存档，普通巡察者不进入；队友不能隔着副本相互看见或交物，死亡后仍可观战存活队友。

规则怪谈由房主建房时统一启用，队员本机扩展设置不能改变合作局。规则组相同，阅读、批注、规则记录及纸飞机支线、窗内视线、体检的个人选择与损益独立。个人幻觉不会暂停全队或直接跳动共享日历；《盗梦空间》梦醒仅结算本人的恢复、违规和睡眠冷却，共享时间继续自然推进。合作记录不写入单人成就。

传送门隧道是路线场景，不是个人梦境副本；每人的返回点分别保存，多人先后进入不会覆盖彼此位置。主体异象、粉笔预告、笑脸、残留痕迹与跨区域巡察视听表现均保留。

## 存档、断线与退出

房主每 30 秒及关键操作后保存，也可手动点击「保存合作进度」。退出时再保存一次。合作文件位于 Godot `user://cooperative/`，与单人槽位、成就及速通记录分开：

| 文件 | 内容 |
| --- | --- |
| `room.json`、`room.json.bak` | 房主的整局存档及上一个完整备份；临时写入、校验后替换。 |
| `connection.json` | 本机最近地址、昵称和原成员重连凭据；不要发送此文件给别人。 |
| `results.json` | 本机最近至多 100 局合作结果，包括成员、参与时长、个人生死、全队结局和调试标记。 |

合作相册另存于 `user://cooperative-album.json`，不进入房主检查点。手机按实例保存，个人小游戏、支线、躲柜计时与返程位置进入房主存档；旧版合作存档缺少的新增字段采用默认值。恢复时重新分配会话与操作标识、清理无对应任务的占用，迟到的回答、关闭窗口和全队确认不能作用于新操作。

原成员断线保留 60 秒，身体停止移动但不获得无敌。点击「重连上次房间」恢复同一个角色、背包与进度；昵称不是身份，改昵称不能接管别人的角色。开局后不允许新成员补位；超时或被房主移除后，原凭据也不能再占用该角色。

房主退出会中断整局服务，客机停止预测并显示重连／返回入口。房主重新建房时可选择「恢复合作存档」，原成员使用自己的重连凭据回到大厅，准备后加载。恢复会切换会话代次，旧连接、旧场景输入和旧请求不会重放。已结算的存档不能继续开始一局。

## 调试与维护

默认队伍页只显示成员、天赋与准备／开始按钮。「队伍操作」提供交付物品、全队暂停和存档等操作。身份、RTT、抖动、输入序号、已确认帧、收发字节、校正误差折叠在「连接帮助」；房主另外查看活动物理区域、巡察目标及未确认快照。房主的恢复状态和传送操作在其内部的「房主调试工具」，统一经过权威命令，并给整局加调试标记；客机伪造这些命令会被拒绝。单人调试面板的直接写状态入口不用于合作局。

入口、协议、自动测试和实际验证范围见[局域网联机验证](局域网联机验证.md)。三平台真实设备互通与自然四人完整游玩仍需要设备验收；软件渲染窗口或回环网络测试不能代替它们。
