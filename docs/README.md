# 项目文档

本目录描述 **Godot 移植版**。旧 Web 版的设计与实现可供核对，但不代表新版本已经交付。

| 文档 | 用途 |
| --- | --- |
| [架构与模块接口](架构与模块接口.md) | 组合入口、状态归属、模块协议、输入、时钟与存档边界 |
| [移植接入指南](移植接入指南.md) | 旧模块映射，接入玩法、房间和资源的步骤与验收 |
| [框架验证记录](框架验证记录.md) | 已执行的测试、画面证据与尚未验证的范围 |
| [正式校园验证记录](正式校园验证记录.md) | 正式校园建筑、碰撞与出入口的验证结果和限制 |
| [计划目录](plan/README.md) | 框架交付状态、后续移植顺序与依赖 |
| [贡献指南](../CONTRIBUTING.md) | 开发、验证与提交约定 |
| [资源约定](../assets/README.md) | 坐标、碰撞、命名、导入与授权记录 |

旧版参考固定到 [Web 仓库 `0bf508a`](https://github.com/wd-fz/wd-fz.github.io/tree/0bf508a47eac154c2a7047cdb45d314f61c48fdc)。后续改变参考基线时，在对应功能的迁移记录中单独注明，不暗中更换验收口径。
