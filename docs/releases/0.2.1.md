# v0.2.1 · 界面、操作与光影

提供 Android ARM64、Windows x86_64 和 Linux x86_64 正式包。三个平台继续使用 Vulkan：Android 为 Mobile，桌面为 Forward+。

## 本次更新

- 统一主菜单、暂停、设置和游戏内界面的墨色主题、暖白文字与衬线标题；优化 HUD 卡片、交互提示和准星反馈。
- 设置新增「键位」页：每个动作支持两个键位、冲突互换、恢复默认和保存；游戏提示跟随绑定变化。Esc 仍固定用于暂停。
- 触屏布局支持逐个拖动与缩放七个操作控件、调整整体透明度和网格吸附；已有三组布局自动迁移。继续优先维护横屏。
- 五档画质增加分级灯光投影、辉光、阴影精度与模型 LOD 预算，桌面低两档用 FSR 1 放大，Mobile 使用受支持的双线性放大；精细及以上改善灯光对比与手电投影。Forward+ 开启相应档位的环境光遮蔽，最高档增加体积雾；Mobile 不启用环境光遮蔽、辉光与体积雾。
- 规避 Mobile 新后处理触发的档案回放卡死：暂时关闭 Mobile 的 FXAA 与辉光，并固定工作线程池为 8，空缓存下全部档案回放通过；桌面效果保留，高档 MSAA 不变。已在软件 Vulkan 复现并验证相关回放；底层是 Godot 已知的编译死锁，后续稳定引擎修复后再验证这两项效果。

## 下载与启动

| 平台 | 安装包 | 要求与启动方式 |
| --- | --- | --- |
| Android | `wdfz-0.2.1-android-arm64.apk` | ARM64、Android 7.0+、支持 Vulkan 的设备；安装 APK |
| Windows | `wdfz-0.2.1-windows-x86_64.zip` | x86_64、支持 Vulkan 的显卡与驱动；完整解压后运行 `wdfz.exe` |
| Linux | `wdfz-0.2.1-linux-x86_64.zip` | x86_64、Vulkan 驱动、中文系统字体（例如 Noto Sans CJK）；完整解压后运行 `wdfz.x86_64` |

桌面可执行文件与 `wdfz.pck` 须放在同一目录。Linux 若解压后丢失执行权限，运行 `chmod +x wdfz.x86_64`。每个平台附带 SHA256 校验文件和 `.build.json` 构建记录。

Android 从启动时即横屏并强制全屏，菜单与设置不显示全屏开关。Windows／Linux 新配置默认窗口化，保留用户已有的全屏选择。Linux 首选原生 Wayland，连接失败时回退到 X11，也可追加 `--display-driver x11`。

## 升级与验证

Android 正式包沿用 `org.wdfz.godot` 和原正式签名，版本代码提升为 3，可覆盖升级 v0.1.0／v0.2.0。Debug 包仍独立安装，其存档不自动迁移。旧公开版本的附件保持原样。

发布要求相同来源提交的完整无窗口回归、Vulkan Forward+／Mobile 窗口回归和桌面导出检查通过。Linux 正式包分别检查原生 Wayland、X11、默认窗口启动、全屏切换、Vulkan 渲染及导出资源；Android 校验正式签名、版本、不可调试、启动横屏与全屏、Vulkan 功能声明、ARM64 和 16 KB 对齐。

Linux 自动运行使用软件 Vulkan；Windows 已验证导出但未做真机验收或代码签名。Android 真机与真实 GPU 性能未在本次自动流程中验收，高画质档的设备表现仍需实测。
