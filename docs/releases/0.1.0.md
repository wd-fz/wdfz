# v0.1.0 · 首个公开 Android 版

武大附中 · 里世界 Godot 移植版首次公开发布。探索校园、调查怪谈、收集物品，寻找离开里世界的路线。

## 下载与安装

- 安装 `wdfz-0.1.0-android-arm64.apk`。要求 ARM64 设备、Android 7.0 及以上。
- 使用正式密钥签名，包名 `org.wdfz.godot`，关闭 Android 调试标记和默认开发工具入口。
- 与此前的 Debug 包分开安装，数据各自保存；安装公开版不会自动带入 Debug 包的进度。
- 同时提供 APK 的 SHA256 文件与构建来源、签名证书指纹等元数据。

## 本版内容

- 正式校园与主要公开玩法：校园日程、调查与背包、巡察者、异象和多条结局路线。
- Android 从系统启动阶段即声明横屏，支持左右横屏翻转；默认全屏。
- 主菜单、暂停、设置及其余面板统一采用新界面；主要操作突出显示，长列表可滚动。
- 背包、笔记和档案使用条目卡片；通关记录分行展示；手机和小游戏采用横屏布局。
- 设置按画面、声音、操作、舒适、数据分类，更改即时生效并保存。
- 修复坐下时站起与翻找提示交替，以及多指触控和奔跑切换问题。

## 验证范围

发布构建会运行完整无窗口回归，并检查正式签名、版本与包名、启动横屏声明、ARM64 库、16 KB 对齐、资源完整性和 SHA256。界面另已进行原生窗口渲染及合成触控验证。

这是首个公开版本；尚未完成 Android 真机全面验收。仅维护横屏，竖屏不受维护。设备性能与兼容性问题可通过仓库 Issues 反馈，并附设备型号、Android 版本和复现步骤。
