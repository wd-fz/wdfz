# v0.5.0 · 连续校园与合作玩法补全

提供 Android ARM64、Windows x86_64、Linux x86_64 正式包。本版包含 v0.4.1 之后的局域网连接修复、整校常驻空间、水杯等异象触发修正，以及合作玩法与存档一致性更新。

## 整个学校连在一起

- 普通校园的 40 个区域共用同一个三维与物理世界，包含室外、楼层、楼梯、连廊、车库和正常电梯。
- 首次进入时统一准备校园，之后进出楼、上下楼和普通区域内传送不再读取、替换整套模型。远处显示建筑外观，附近展开室内细节。
- 普通校园中的队友、地面物品、巡察者视听提示按真实位置与遮挡处理，门内外不再仅凭房间编号隔开。室内外保持统一昼夜环境，停电和车库保留特殊光照。

## 联机连接与队伍操作

- 修复握手尚未完成就反复重建连接、迟到应答丢失，以及 ENet 服务端带宽配置异常导致输入大量丢失的问题。
- Android 同一 Wi-Fi 下，房主建房和客户端发现、加入、重连均选择物理 Wi-Fi 网络；退出局域网会话后恢复网络选择。此操作遵守系统与 VPN 的旁路权限，远程 Terracotta 模式保持原选路。
- 完善附近／远程房间入口、横屏触控、断线后的原角色重连、移除队员确认、队伍状态与连接诊断。
- 房主死亡后仍可维持房间并观战；正式离队统一清理角色、车辆、电梯、持续操作和物品归属。

## 合作通关与状态修复

- 修复车门任务完成后无法正常发起全员上车的问题；车辆确认、驾驶、失败恢复和司机断线接管分别处理。
- 修复普通设施被长期独占、过期回答或关闭指令干扰新操作、外国语路线掉队后无法重新归队，以及加载／恢复时死亡成员状态不一致的问题。
- 手机电量、无线和下载进度随同一部手机转交；治疗中的急救包失去后取消治疗。唯一材料、地面拾取、隧道返程和特殊空间死亡回收保持各自归属。
- 四人座位、交互提示、原教室充电、讲台移交单与临时补给接回实际操作入口。车库黑影同时考虑队友灯光。
- 全队同意课堂整理后，按六倍完整模拟推进；队友行动或遇险时恢复正常速度。补齐个人躲柜计时、粉笔预警、幻觉、痕迹、笑脸和持续翻越输入。

## 个人活动、隐藏路线与规则怪谈

- 手机纸飞机和机房贪吃蛇接入合作模式，由房主运行规则、结算奖励，客户端只发送操作。相机和相册保存在本机，照片不上传给队友；闪光对巡察者的影响由房主判定。
- 隐藏路线由个人探索，真正结局需全体存活成员确认后共同结算。《管制刀具》的个人假结局只让本人回到座位。
- 迷宫与梦境仅影响进入者，队友继续在校园行动。梦境完成后返回入梦前的位置等待队伍决定；拒绝后可以重新发起结局确认。
- 房主建房时统一选择是否启用规则怪谈，所有队员使用相同规则组；个人阅读、选择与记录分别保存。合作记录与单人成就分开。
- 修复联机快照重置手机页面、关闭手机后小游戏未结束，以及收起手机手部模型时的材质释放错误。

## 异象触发

- 未预告的异象按触发时的实际地点抽取，减少提前锁定常见事件后，让新地点专属异象难以出现的情况。
- 临时抽中的水杯立即显示窗台晃动、声音和提示，并保留完整预警时间。落点固定在触发位置，玩家走开能躲过，不会追着玩家落下；预警及落点支持存档恢复。

## 下载与升级

| 平台 | 文件 | 启动方式 |
| --- | --- | --- |
| Android | `wdfz-0.5.0-android-arm64.apk` | ARM64、Android 7.0+、支持 Vulkan；安装 APK |
| Windows | `wdfz-0.5.0-windows-x86_64.zip` | 完整解压，运行 `wdfz.exe`，需要 Vulkan 驱动 |
| Linux | `wdfz-0.5.0-linux-x86_64.zip` | 完整解压，运行 `wdfz.x86_64`；需要 Vulkan 驱动及中文字体，例如 Noto Sans CJK |

**房主和所有客户端都须更新到同一版本。** Android 正式包继续使用 `org.wdfz.godot` 和原正式签名，版本代码为 7，可覆盖升级此前正式包；Debug 包独立安装，其进度不会自动迁入正式版。旧合作存档缺少的新增字段采用默认值恢复。

Android 启动即横屏并强制全屏；Windows／Linux 默认窗口化，Linux 原生支持 Wayland 和 X11。桌面端请保留 `wdfz.pck` 和整个 `terracotta/` 目录；Linux 若丢失执行权限，可运行 `chmod +x wdfz.x86_64`。每个平台均附 SHA256 和 `.build.json` 构建记录，共九个附件。

## 发布验证

发布流程要求本次来源提交的完整无窗口、Vulkan Forward+／Mobile 窗口回归、联机规则与真实 ENet、官方 Terracotta 通道，以及桌面导出检查全部成功。Android 另检查正式签名、不可调试标记、清单权限、横屏／全屏、Vulkan 和 16 KiB 对齐；Linux 导出包检查 X11／Wayland 启动与实际 Vulkan 渲染。九个附件上传后核对大小和 SHA256，全部一致后公开。

自动验证不等同于 Android／Windows 真机或自然四人整局验收；跨运营商、手机 VPN 环境及 Snapdragon 8 Elite 功耗仍需实际设备验证。开发期间的长测及各环境结果见[联机验证记录](https://github.com/wd-fz/wdfz/blob/v0.5.0/docs/局域网联机验证.md)。
