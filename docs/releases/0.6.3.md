# v0.6.3 · 入校流程与校园追逐

## 入校、手册与地图

- 新游戏统一从角色和天赋选择开始。加载画面按场景准备阶段更新进度。合作模式会显示队伍就绪人数，等队伍完成加载再一同入校。
- 手册分开呈现当前目标、规则、调查笔记和背包入口。HUD 新增小地图，校园总图用游戏内校园模型生成，显示楼栋、方位和调查目标。
- 按 720 云实景校正入口。教学楼北侧拱门朝向绿色广场，原南门已封闭。行政楼、实验楼、宿舍和相连的步道也已校正。

## 巡察、车库与随身物品

- 巡察者看得更远，追逐速度超过玩家奔跑速度。步行保持安静，奔跑的脚步能引来调查。SAN 下降会让巡察者获知大致区域。
- 车库黑影戴上白色自发光笑脸。手电光束照中后，它会瞬移到远离玩家、避开光束的位置。追车增加转向延迟和高速侧滑，高速擦碰护栏会损耗车况。
- 科技党的随身手机永久占用一格背包，无法丢弃或交给队友。旧存档缺失的手机会在读档时补回。
- 注视洗手池上的镜面每秒消耗 2.8 SAN。移开视线即可停止消耗。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Android ARM64 | `wdfz-0.6.3-android-arm64.apk` |
| iPhone／iPad ARM64 | `wdfz-0.6.3-ios-arm64-unsigned.ipa` |
| Windows x86_64 | `wdfz-0.6.3-windows-x86_64.zip` |
| Linux x86_64 | `wdfz-0.6.3-linux-x86_64.zip` |

Android 正式包版本代码为 11，可覆盖安装在上一正式版上。iOS 版使用原生 Metal，需要 iOS／iPadOS 14 或更新版本，下载后须自行签名安装。桌面版解压后运行，Linux 支持 Wayland 和 X11。

联机时房主和队友都需要更新到 v0.6.3。各平台安装包均附 SHA-256 校验文件和构建记录。
