# v0.4.0 · 先听见，再看见：恐怖节奏、新开机动画与联机修复

提供 Android ARM64、Windows x86_64 和 Linux x86_64 正式包。三个平台继续使用 Vulkan：Android 为 Mobile，桌面为 Forward+。

## 本次更新

### 恐怖节奏（部分为玩法改动）

- 巡察者在看见之前就能听见：按它走到你身边要走的路程分三档，远处是门轴声或零星脚步，中距离是来自它方向的稳定脚步，近处脚步更重，偶尔有呼吸。这些声音与普通的虚惊声相同，单独一声不能说明什么；真的靠近时，方向不变、越来越近。关闭声音时可看声音字幕。
- 它追你时，没有预告过的异象不会叠在追逐上开始，最早在追逐结束 8 秒后出现；通过粉笔或钟摆预告过的异象仍按预告时间到来。
- 从第 2 天起，课间可能在室内墙上或门上看到一张「教务处通知」，三行里有一行用红笔写、没有盖章，是假的。拿课表核对就能分辨；照做假的那条，就会按现有的上课、熄灯或检查规则被记下。看过的通知会写进调查笔记。
- 柜子仍然能躲。没有威胁时在里面待太久，柜子自己会有反应：先是里面的敲击声，然后是呼吸声，最后会把你推出来，扣 4 点 SAN（不会低于 1）。只要巡察者还构成威胁就不计时，不会把你推进危险里。合作模式不受影响。
- 再次进入同一个房间时，墙上或门上偶尔多一行粉笔字。
- 刚经历异象、追逐或检查之后，零星的虚惊声会变少，给你喘口气；长时间平静之后会稍微变多。
- 试玩记录（调试面板中手动开启）新增恐惧节奏统计：遭遇间隔、强制威胁叠加、回头、躲藏、追逐脱离、死因与重复死亡、跳过和暂停。只存在本机，不上传。

### 开机与加载

- 开机动画重做为「傍晚六点的教室」：日光灯闪几下后亮起，照亮墙上的挂钟；秒针走到 18:00，标题浮现；随后秒针倒退一格，钟面泛红，灯管熄灭，画面全黑后接上主界面的「睁眼」进入动画。任意键或点击淡到黑跳过；开启「减少闪烁」时只做 1.4 秒的平缓版本，不闪烁也不倒退。
- 开局加载画面加入同一只挂钟（分针随进度从 17:00 走向 18:00）、雾气流动的暗墙、每 4.5 秒更换的氛围短句，以及带余烬光点的进度线、当前步骤和百分比。

### 联机

- 修复局域网「查找附近房间」：查找请求现在会发往本机每块网卡所在的网段和本机自身，装了 VPN 或虚拟网卡的 Windows 电脑也能找到房间；Android 当房主时能收到查找请求（安装时新增 Wi-Fi 组播权限）；同一房间不再重复列出；查找时显示「正在查找…」，没找到时列出排查建议。
- 远程合作（Terracotta）加入时，本机组件偶尔一次没有回应不再直接放弃，连续 3 次没有回应才提示失败。

## 下载与启动

| 平台 | 安装包 | 要求与启动方式 |
| --- | --- | --- |
| Android | `wdfz-0.4.0-android-arm64.apk` | ARM64、Android 7.0+、支持 Vulkan 的设备；安装 APK |
| Windows | `wdfz-0.4.0-windows-x86_64.zip` | x86_64、支持 Vulkan 的显卡与驱动；完整解压后运行 `wdfz.exe` |
| Linux | `wdfz-0.4.0-linux-x86_64.zip` | x86_64、Vulkan 驱动、中文系统字体（例如 Noto Sans CJK）；完整解压后运行 `wdfz.x86_64` |

桌面可执行文件与 `wdfz.pck` 须放在同一目录，并保留整个 `terracotta/` 子目录。Linux 若解压后丢失执行权限，运行 `chmod +x wdfz.x86_64`。每个平台附带 SHA256 校验文件和 `.build.json` 构建记录。

## 升级与验证

Android 正式包沿用 `org.wdfz.godot` 和原正式签名，版本代码提升为 5，可覆盖升级 v0.1.0 至 v0.3.x。旧存档可直接读取。注意：联机双方须使用相同版本。

发布要求同一来源提交的完整无窗口回归、Vulkan Forward+／Mobile 窗口回归、局域网／真实 Terracotta 通道回归和桌面导出检查全部通过。本版新增恐怖节奏专项、房间发现与远程加入容错的单元测试。

未验证：恐怖节奏在自然长局中的频率与观感、真机听感；Windows 多网卡与 Android 房主的房间发现；Android 真机性能与发热。Windows 包已验证导出，但未做真机验收或代码签名。
