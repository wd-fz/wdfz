# v0.6.2 · 首日调查与校园更新

## 首日探索

- 西小门的纸质回执改为可跳过的入门调查。玩家可以用名牌了解点名，在保安岗拿手电、查底联，再按地图找到闸机。试走之后会继续当前游戏，笔记会提供车辆和电子白名单的线索。
- 游戏左上角的「下一步」随调查更新。学生会检查时会先提示如何应对。声音字幕与对应设置已移除。
- 校园加入可调查的现场和纸样。亲手查到的记录会写入手册，相关发现会在后续结局中得到回应。

## 校园场景

- 依据校园实景校正教学楼、行政楼、实验楼等建筑的相对位置和连廊，补充庭院、室内家具和场景标识。
- 校园总图同步三维校园的位置。切换跟踪线索可以查看目标建筑和方位。

## 合作联机

- 修复房主准备校园时，客机在加载阶段过早判定连接超时的问题。重连加载采用相同的等待时限，遗失的快照确认可以补发。
- 队友可以独立完成西小门的入门调查，发现会写入团队笔记。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Android ARM64 | `wdfz-0.6.2-android-arm64.apk` |
| iPhone／iPad ARM64 | `wdfz-0.6.2-ios-arm64-unsigned.ipa` |
| Windows x86_64 | `wdfz-0.6.2-windows-x86_64.zip` |
| Linux x86_64 | `wdfz-0.6.2-linux-x86_64.zip` |

Android 正式包版本代码为 10，可覆盖安装在上一正式版上。iOS 版使用原生 Metal，需要 iOS／iPadOS 14 或更新版本，下载后须自行签名安装。桌面版解压后运行，Linux 支持 Wayland 和 X11。

联机时房主与队友都需要更新到 v0.6.2。各平台安装包附 SHA-256 校验文件和构建记录。
