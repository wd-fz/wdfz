# v0.3.0 · 好友合作、远程邀请码与新版界面

提供 Android ARM64、Windows x86_64 和 Linux x86_64 正式包。三个平台继续使用 Vulkan：Android 为 Mobile，桌面为 Forward+。

## 本次更新

- 新增 2–4 人局域网合作：独立 SAN、背包与天赋，共享校园和剧情，支持物品交付、跨楼层探索、死亡后观战、房主保存与恢复、原成员断线重连和六条公开结局的共同结算。合作存档及结果与单人模式分开。
- 新增「远程合作 · Terracotta」：房主创建房间并分享邀请码，好友异地加入，无需自行租服务器。Windows／Linux 完整包附带 Terracotta 0.4.2，Windows 同时附带其运行库；Android 内置原生组件，首次使用须允许仅限本游戏的系统 VPN。
- 合作界面支持横屏触控和滚动；修复满员房间同时掉线后的连接名额释放、通道重建后恢复原角色、退出大厅后再次加入，以及恢复存档大厅保留原成员的问题。双方须使用相同版本，不能混用早期合作测试构建。
- 启动先播放一段开机动画（血色裂缝、标题从噪点中浮现、心跳红光），任意键或点击可跳过；开启「减少闪烁」时只做短暂淡入淡出。
- 主菜单重做为固定在左侧的侧边菜单：进入时毛玻璃面板沿脊柱撕开并自动展开，单人入口包括「继续入梦／新的轮回／画廊与遗物／感官设置／逃离现实」，原有入口都收在其中。背景默认是一张缓慢转动的校园全景图（教学楼前草坪的傍晚实景，预先渲染，菜单背后不做实时 3D 渲染）；「设置 → 画面 → 主菜单实景环绕」可关闭，改为静态夜景图。主菜单静置时自动降到 30 帧，有操作立即恢复。开启「减少闪烁」时直接显示静态展开的菜单。暂停菜单不变。
- 背包丢弃的物品不再消失，而是留在脚边地上，低头看着它按交互键捡回，随存档保存；背包改为格子＋详情两栏，丢弃前需确认。HUD 快捷栏改为带名字的卡片，提示条改为贴字宽的半透明胶囊。
- 天赋选择改为独立的选择页，先预览再确认；菜单、档案、设置等列表统一触屏滑动，滑动不会误触按钮。
- 死亡演出重做：真实死亡就在你所在的地方演出，不再切到另一个房间；每种死因都有自己的道具与动作（登记本、后视镜、迎面的车灯与挡风玻璃裂纹、出口指示牌、合拢的墙、被抹掉的门、挂着的空校服、木壳广播音箱等），人物换成穿校服的人形与空眼窝的头，地上伸出的手、跳脸与回头笑脸也换成新模型。档案馆的回放用重做后的独立布景。死因、触发、时长与结算不变。
- 画质可独立调整分辨率、模型／材质／粒子、阴影、后期与抗锯齿，支持帧率上限与独立垂直同步；Vulkan 场景提交与传送门加载更省。
- 开发工具增加性能／物理诊断、事件筛选、位置书签、逻辑步进与死亡预览控制（正式包默认不显示）。

## 下载与启动

| 平台 | 安装包 | 要求与启动方式 |
| --- | --- | --- |
| Android | `wdfz-0.3.0-android-arm64.apk` | ARM64、Android 7.0+、支持 Vulkan 的设备；安装 APK |
| Windows | `wdfz-0.3.0-windows-x86_64.zip` | x86_64、支持 Vulkan 的显卡与驱动；完整解压后运行 `wdfz.exe` |
| Linux | `wdfz-0.3.0-linux-x86_64.zip` | x86_64、Vulkan 驱动、中文系统字体（例如 Noto Sans CJK）；完整解压后运行 `wdfz.x86_64` |

桌面可执行文件与 `wdfz.pck` 须放在同一目录，并保留整个 `terracotta/` 子目录。Linux 若解压后丢失执行权限，运行 `chmod +x wdfz.x86_64`。每个平台附带 SHA256 校验文件和 `.build.json` 构建记录。

Android 从启动时即横屏并强制全屏，菜单与设置不显示全屏开关。Windows／Linux 新配置默认窗口化，保留用户已有的全屏选择。Linux 首选原生 Wayland，连接失败时回退到 X11，也可追加 `--display-driver x11`。

## 升级与验证

Android 正式包沿用 `org.wdfz.godot` 和原正式签名，版本代码提升为 4，可覆盖升级 v0.1.0／v0.2.x。Debug 包仍独立安装，其存档不自动迁移。旧存档可直接读取；地上的物品是新加入的存档内容，旧存档读取后地上为空。旧公开版本的附件保持原样。

发布要求相同来源提交的完整无窗口回归、Vulkan Forward+／Mobile 窗口回归、局域网／真实 Terracotta 通道回归及桌面导出检查通过。合作检查覆盖四人同步、通道重建与原角色恢复、慢加载、弱网、恢复存档、共同结局，以及 X11／Wayland／Vulkan Mobile 界面。Linux 正式包分别检查原生 Wayland、X11、默认窗口启动、全屏切换、Vulkan 渲染及导出资源；Android 校验正式签名、版本、不可调试、启动横屏与全屏、Vulkan 功能声明、ARM64、16 KB 对齐和远程组件。发布前还核对九个附件的校验值、来源提交、固定版本远程组件与 Windows 运行库。

Linux 自动运行使用软件 Vulkan；Windows 已验证导出但未做真机验收或代码签名。Android 真机与真实 GPU 性能未在本次自动流程中验收；菜单背景的全景图与新死亡演出在手机上的帧率与发热仍需实测。

合作首版开放六条公开结局；隐藏路线、个人特殊空间、DLC、手机小游戏和相册等内容仍限单人。房主须保持游戏运行；尚无房主迁移和公共匹配。Terracotta 不能保证所有网络都能打洞，跨运营商及 Android 真机 VPN 尚未实测。Android 同时通常只允许一个 VPN，连接前请自行决定是否切换。使用步骤及支持范围见[局域网合作](../局域网合作.md)与[远程合作](../远程合作.md)。
