# v0.6.5 · 触屏联机修复

修复 Android 玩家加入联机房间后，拖动摇杆却无法移动的问题。移动包超过大小上限时，会优先保留最新的摇杆和视角输入。双进程联机测试覆盖了触屏移动和松手停车。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Android ARM64 | `wdfz-0.6.5-android-arm64.apk` |
| iPhone／iPad ARM64 | `wdfz-0.6.5-ios-arm64-unsigned.ipa` |
| Windows x86_64 | `wdfz-0.6.5-windows-x86_64.zip` |
| Linux x86_64 | `wdfz-0.6.5-linux-x86_64.zip` |

Android 正式包版本代码为 13，可覆盖升级此前的正式版。iOS 版使用 Metal，需要 iOS／iPadOS 14 或更新版本，下载后须自行签名安装。桌面版解压后运行，Linux 支持 Wayland 和 X11。

联机前请让房主和所有队员更新到 v0.6.5。四个平台的包均附 SHA-256 校验文件和构建记录。
