# v0.4.1 · 联机入口修复、渲染减负与包体积优化

提供 Android ARM64、Windows x86_64、Linux x86_64 正式包。包含此前 v0.4.0 草稿中的[恐怖节奏、开机与加载改进](https://github.com/wd-fz/wdfz/blob/v0.4.1/docs/releases/0.4.0.md)，以及以下更新。

## 联机更容易加入

- 修复附近房间持续刷新时，房间按钮在手指按下与抬起之间被重建，导致点击没有提交加入的问题。现在点房间即可加入，滑动列表不会误加入。
- 联机入口统一为「与好友联机」，选择附近／远程，再创建／加入。附近房间自动查找，远程只需一个邀请码；称呼、端口、地址和诊断放进设置或连接帮助。
- 创建默认四人房间，大厅准备／开始按钮固定在底部。触屏滚动、小尺寸横屏与输入键盘避让同步改善。
- 房主明确监听 IPv4；加入过程显示连接、校验和进入房间的进度，支持取消与有限重试。重复握手不会重复创建角色，迟到应答不会把已进入的大厅退回等待状态。
- 联机数据改用四个独立 ENet 数据通道，移除对场景 RPC 节点缓存的依赖，避免弱网重连时出现节点缓存错误。保留原身份重连、心跳超时、消息大小与频率限制。

**联机协议已升级，房主和所有客户端须安装同一版本。** 两台 Android 使用同一 Wi-Fi／热点时，房主需保持游戏在前台；仍无法加入可在双方「连接帮助」复制诊断。

## 场景、渲染与体积

- 校园与各楼层按连接区域加载，减少进出楼时整场景切换，室内外共用昼夜光照。
- 修复上楼时目标楼层被后续预览插队、排队中的楼层重复构建室外模型的问题。先准备可进入的区域，并在实际执行加载时复用刚完成的相邻模型。
- 修复同学模型、死亡演出和场景道具替换材质时的生命周期问题，避免渲染器读取已释放的材质；跨楼层回归检查同步适配后台加载，验证真实行走后的切换完成。
- 调整所有画质档的模型层级、可见范围、灯光与阴影预算，削减高成本的画面效果；保留独立画质设置和帧率限制。
- 移除导出包中的退役模型档，合并相同纹理数据，并优化原生资源的无损压缩。此前同源对照中，资源包从 495.3 MiB 降至 211.0 MiB，Android Debug 从 563.3 MiB 降至 287.5 MiB；本次正式包大小以附件为准，详见[包体积优化记录](https://github.com/wd-fz/wdfz/blob/v0.4.1/docs/包体积优化.md)。
- 三个平台继续使用 Vulkan；Android 使用 Mobile，桌面使用 Forward+。Android 从启动即横屏并强制全屏；Windows／Linux 默认窗口化，Linux 原生支持 Wayland 和 X11。

## 下载与升级

| 平台 | 文件 | 启动方式 |
| --- | --- | --- |
| Android | `wdfz-0.4.1-android-arm64.apk` | ARM64、Android 7.0+、支持 Vulkan；安装 APK |
| Windows | `wdfz-0.4.1-windows-x86_64.zip` | 完整解压，运行 `wdfz.exe`，需要支持 Vulkan 的驱动 |
| Linux | `wdfz-0.4.1-linux-x86_64.zip` | 完整解压，运行 `wdfz.x86_64`；需要 Vulkan 驱动及中文字体，例如 Noto Sans CJK |

桌面端请保留 `wdfz.pck` 和整个 `terracotta/` 目录。Linux 若丢失执行权限，可运行 `chmod +x wdfz.x86_64`。每个平台附带 SHA256 和 `.build.json` 构建记录。

Android 正式包继续使用 `org.wdfz.godot` 与原正式签名，版本代码为 6，可覆盖升级此前正式包；Debug 包独立安装。本次不改变单人或合作存档结构。

## 发布验证

发布流程要求同一来源提交的完整无窗口回归、Vulkan Forward+／Mobile 窗口回归、局域网与官方 Terracotta 通道测试、桌面导出检查全部成功后才能公开。Linux 导出包检查 X11／Wayland 启动和实际 Vulkan 渲染；Android 检查正式签名、清单权限、横屏／全屏、Vulkan 与 16 KiB 对齐。全部九个附件在上传后校验大小和摘要。

自动验证不等同于 Android／Windows 真机验收；尚未在用户的两台 Android 设备、热点环境或 Snapdragon 8 Elite 上验证连接与功耗。软件 Vulkan 的测试结果不能用作手机性能结论。
