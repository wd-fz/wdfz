# v0.6.4 · 教室醒来

## 从正常校园开始

- 新周目从正常教室里的六科考试开始。30 道题限时十分钟，可提前交卷。满分会激活本局全部天赋。交卷后在课桌上睡去，醒来时全班同时转身看向你。
- 名牌、行政楼的试卷交接单和机房日志留下了可以互相核对的线索。西小门纸质核验后，手册会指向后续调查。
- 同化满值触发《假正常》，回到教室亲眼看到有人替自己举手应到。做过纸样实验并真正逃离时，可在北门岗亭的演出中看到玻璃盒里的结果。《外国语学生》的接待证更正为「武汉大学附属中学 · 高中」。

## 校园与合作

- 教学楼一楼的教室门朝北，走廊通向绿色广场。打开了北侧柱廊，并恢复课桌和墙面的模型配色。
- 升级至 Godot 4.7.2。将外景读取移至后台，减少入校与跨区时重复读取和处理模型。
- 合作考场共用十分钟答题时间，成绩页最多等待 30 秒。离线队友按已作答的内容结算，回来可以直接加入已经开始的校园。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Android ARM64 | `wdfz-0.6.4-android-arm64.apk` |
| iPhone／iPad ARM64 | `wdfz-0.6.4-ios-arm64-unsigned.ipa` |
| Windows x86_64 | `wdfz-0.6.4-windows-x86_64.zip` |
| Linux x86_64 | `wdfz-0.6.4-linux-x86_64.zip` |

Android 正式包版本代码为 12，可覆盖升级此前的正式版。iOS 版使用 Metal，需要 iOS／iPadOS 14 或更新版本，下载后须自行签名安装。桌面版解压后运行，Linux 支持 Wayland 和 X11。

合作联机时请将所有队员更新到 v0.6.4。四个平台的包均附 SHA-256 校验文件和构建记录。
