# v0.6.0 · 替我答到

同桌递来一张纸条。他愿意在点名时替你应声，可北门旁的保安岗里，已经有了一张签着你名字的单子。

## 第一次离校

- 在首页点「走进教室」即可开始调查。想挑选角色或天赋，可以进入「自选开局与玩法」。有存档时，首页会优先显示继续游戏。
- 点名时，你可以留在自己的座位，也可以让空座替你应声。北门岗亭的底联、西小门的闸机和结局回执会记得这一局实际发生过什么。
- 走丢时可以翻开校园图，看自己在哪、目标在什么方位。笔记会保留亲手查到的证词，暂停页也能接着看下一件要做的事。已有单人存档中查过的底联可继续用于核验。
- 开车与放学广播两条路线加入了同桌和妹妹的后续。纸质回执与电子白名单分别记入档案和速通成绩。

## 和朋友一起走

- 房间里可以从四名学生中选角。进入校园后能看到队友的全身模型，以及随实际动作切换的站立、行走和奔跑动画。
- 队友把名字借给空座时，留在同一间教室的人可以看到那张座位上的变化。证词全队都能翻阅，底联按人领取，去西小门的存活队员需要分别确认离校。
- 修复了客户端走路时被拉回一截的问题，减少了联机时重复更新画面和模拟的开销。弱网断线后，房主会给旧连接留出释放时间，让原成员有机会回到自己的角色。

## 校园与操作

- 里世界里的同学、讲台上的老师和巡察者有了新的动作和声音。露天路面会在暴雨前变湿，给你寻找连廊的时间。
- 修复了部分建筑的墙体显示和碰撞、讲台交互、第一人称看到自己下半身等问题。开场演出会使用所选学生的模型。
- 新版标题画面、暂停菜单和天赋预览适配横屏操作，大字号下的常用入口也更容易点到。
