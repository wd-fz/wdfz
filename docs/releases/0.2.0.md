# v0.2.0 · Android / Windows / Linux

三个平台的正式版统一使用 Vulkan。Android 使用 Godot Mobile 渲染器；Windows 与 Linux 使用 Forward+，不提供 OpenGL 回退。

## 下载与启动

| 平台 | 安装包 | 要求与启动方式 |
| --- | --- | --- |
| Android | `wdfz-0.2.0-android-arm64.apk` | ARM64、Android 7.0+、支持 Vulkan 的设备；安装 APK |
| Windows | `wdfz-0.2.0-windows-x86_64.zip` | x86_64、支持 Vulkan 的显卡与驱动；完整解压后运行 `wdfz.exe` |
| Linux | `wdfz-0.2.0-linux-x86_64.zip` | x86_64、Vulkan 驱动、中文系统字体（例如 Noto Sans CJK）；完整解压后运行 `wdfz.x86_64` |

桌面可执行文件必须与 `wdfz.pck` 保持在同一目录。Linux 若解压后丢失执行权限，运行 `chmod +x wdfz.x86_64`。每个平台都附带 SHA256 校验文件与 `.build.json` 构建记录。

## 显示与操作

- Android 从启动时即横屏、沉浸全屏，主菜单、暂停菜单和画面设置均隐藏全屏开关；旧的窗口设置不会关闭全屏。左右横屏自动旋转仍可设置。系统手势临时唤出的系统栏由 Android 管理。
- Windows／Linux 新配置默认窗口化，菜单与设置保留全屏切换，之后记住用户的选择；可用 `--windowed` 或 `--fullscreen` 指定启动模式。
- Linux 首选原生 Wayland，不依赖 XWayland；连接失败时回退到 X11，也可手动追加 `--display-driver x11`。
- 继续优先维护横屏比例，竖屏不受维护。

## 升级

Android 正式包沿用 `org.wdfz.godot`、正式签名与数据目录，版本代码从 1 提升为 2，可覆盖升级 v0.1.0。独立的 `org.wdfz.godot.debug` 调试包可以并存，其存档不会自动迁移到正式版。v0.1.0 的公开附件保持原样。

## 验证范围

发布流程要求相同来源提交的完整无窗口回归、Vulkan Forward+／Mobile 窗口回归与桌面导出检查全部通过。Linux 正式包分别验证原生 Wayland 与 X11 下的窗口启动、全屏切换、Vulkan 渲染、动态资源与正常退出。Android 检查正式签名、版本、不可调试、启动横屏与全屏、Vulkan 必需功能声明、ARM64 及 16 KB 对齐。

Linux 自动运行检查使用软件 Vulkan；Windows 当前验证了导出，未在 Windows 真机验收，也未做 Windows 代码签名。Android 真机和真实 GPU 性能仍未在本次自动流程中验收。发布不表示所有设备或长局场景已经穷尽测试。
