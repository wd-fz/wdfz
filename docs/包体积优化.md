# 包体积优化

2026-11-15，基于 `227e6a8` 实施。当前仍有五档画质预设，实际校园模型层级为 0／1／2／3／3。本轮处理导出资源的冗余与存储方式，不更换引擎或模型格式。

## 体积来源与改动

此前 v0.3.0 APK 的 ZIP 目录统计中，压缩后的场景约占 392 MiB、贴图约 80 MiB、Godot 原生库约 67 MiB。代码与界面逻辑占用很小。最新基线 Android 调试包为 **590,649,595 字节（563.3 MiB）**，来源为 Android Debug 工作流 `43701387134`，提交 `227e6a8`，SHA-256 为 `912f11869b88b6f884ba47702ce0f6a6dc369ef827eb5f03fd99729a7a6e4a41`。

采取三项优化：

1. **排除已经停用的第五套校园模型。** `assets/campus_q4/` 加入 `.gdignore` 和所有平台的导出排除项，源文件仍留在仓库。`CampusData` 只列出 0–3 四个受支持的模型层级；旧的层级 4 请求回落到 3。最高两档画质继续使用模型层级 3。
2. **无损重排场景压缩块。** Godot 默认以 4 KiB 块保存导入的 RSCC 场景容器。导出插件重新压缩为最大 1 MiB 的 Zstandard 块；小资源使用较小缓冲。每个输出必须解压并与原始数据逐字节相等，且只有更小时才采用。节点、顶点、LOD、阴影网格、材质、变换和门元数据全部保留。仍由 Godot 原生加载器读取，没有新增游戏运行时解压器。
3. **共享完全相同的贴图。** 对平台无关的导入 `.ctex` 文件按 SHA-256 去重，不改像素、尺寸或导入参数。原图片路径保留 `.import` 入口，指向一份共享纹理；不能简单替换成 `.remap`，否则原生材质以 `Texture2D` 类型加载时会失败。带平台特定压缩格式的纹理仍走引擎原有导出逻辑。

插件位于 `addons/package_optimizer/`，由项目启用，编辑器导出与 CLI 导出均自动执行。插件源代码不进入游戏包。所有脚本、物品／天赋插画、音频、现行模型档、场景、结局和 Terracotta 联机组件继续按原路径提供。

## 同源资源包对照

在同一工作区、Godot 4.6.3、Linux 导出预设下，分别导出改造前和改造后的 PCK：

| 产物 | 优化前 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| 完整 PCK | 519,323,684 B（495.3 MiB） | 221,256,132 B（211.0 MiB） | 57.4% |

剔除停用档之后，剩余 **224 个场景**全部通过无损校验，场景容器从 245,057,036 B 缩小为 153,040,430 B。**786 个贴图引用共享 448 份纹理**，实际纹理从 66,328,988 B 缩小为 57,464,716 B。仅压缩与纹理共享减少约 96.2 MiB，其余收益来自排除停用档。

PCK 不含原生引擎库，不能把其体积直接当成 APK 体积。Android 的准确结果以相同源码的独立 CI 构建及 `.build.json` 为准；本地没有 Android SDK 和真机。

## 验证与复测

```bash
python tools/check.py --static-only
python tools/check.py --mode headless
# 只导出资源包，不需要平台原生模板。
godot --headless --path . --export-pack Linux build/package-check.pck
# 实际 Vulkan 窗口加载包内资源与运行游戏；验证器不进入游戏包。
godot --display-driver x11 --main-pack build/package-check.pck --script tools/ci/export_smoke.gd
# Android 使用既有 SDK／JDK 与官方模板。
python tools/export_android.py
```

导出报告位于 `build/reports/package-size/<输出文件名>.json`。自动构建先删除上次报告，再要求新的无损校验与资源计数，并将报告写入构建元数据。APK 校验同时检查包内优化标记、实际压缩场景与共享纹理、所有导入路径、停用档和编辑器代码排除、ZIP 完整性、签名与 16 KiB 页面对齐。

原生包验证器逐一加载并实例化全部导出的模型，再检查插画、材质、新局、换房间、画质设置、死亡演出和开发工具。压缩单测覆盖空尾块、4 KiB／1 MiB 边界、截断、非法长度和真实 Godot 资源的保存／读取。

本地完整无窗口回归 **21,206 项检查、0 失败**。原生压缩与模型档专项 **30 项、0 失败**；实际 PCK 中 **224 个模型全部加载并实例化**，Vulkan Forward+ 与 Mobile 下的整套包内游戏检查均通过。Android 构建的实际体积在 CI 完成后补录；以上 Vulkan 检查使用 llvmpipe，不能代替 Android 真机验收。

本轮没有删除历史资源或改写 Git 历史，因此仓库克隆体积不会与安装包同步缩小。官方原生引擎库、APK 对齐和签名继续使用原构建方式。
