# 触屏列表与天赋选择

天赋选择采用横屏双栏：左侧浏览卡片，右侧阅读插画、效果与限制，底部始终保留返回和确认。原来的长卡片点击即开局流程已替换。

## 选择与确认

- 进入页面时没有选中项，确认按钮不可用。点击卡片只选中并更新详情，可以继续比较其他天赋。
- 效果、限制与插画来自现有天赋目录；卡片不再承担开局操作。长详情独立滚动。
- 「确认并开始」只提交一次，随后创建实际会话并进入开场。随机天赋也到确认时才抽取。
- 返回或 Esc 取消，恢复菜单焦点；重新打开时清除旧选择和滚动位置。取消速通准备不会启动计时。
- 数字键 1–8 选中，Enter 确认；焦点在返回按钮时 Enter 返回。Tab／Shift+Tab 在本页面循环，Space 仍可操作焦点按钮。
- 底部按钮最小高度为 60 个界面单位。验收覆盖 960×540、844×390、2340×1080 横屏及 85%、100%、150% 字号。竖屏仍不在维护范围。

## 共用列表操作

`TouchScroll` 接收真实手指事件，不依赖系统是否报告触屏，也不需要让桌面鼠标冒充触屏。它接入菜单、暂停、设置、背包、笔记、成就／档案、通关记录、结算、死亡／结局说明、导入说明、手机应用／相册、麦克风列表和开发工具。

| 操作 | 行为 |
| --- | --- |
| 从卡片、文字或按钮上起滑 | 超过 12 个界面单位后取消待定点击，滚动相应内容 |
| 列表没有溢出或滑动方向不能滚动 | 同样取消点击，防止一次滑动变成选择 |
| 松手 | 保留有限惯性；到边界停止，静止时不运行逐帧更新 |
| 系统取消触摸、第二根手指介入 | 取消待定按钮操作，不误用物品或播放 CG |
| 拖动滑条、编辑文字、使用原生下拉菜单、操作地图或游戏画布 | 相应控件保留自己的输入；嵌套列表由内层接管 |
| 桌面鼠标与滚轮 | 保留原生点击、焦点和滚轮行为 |

Godot 的模拟鼠标松开事件可能先于带取消标记的触摸事件到达。组件会等触摸结果确定后再交还松开事件，避免取消手势先触发物品操作。

接入新的持久选择页时，使用 `GameUI.show_selection(title, mode, entries)`；每条提供 `name`、`role`、`effect`、`limit` 和 `art`，确认回传索引，取消回传 `-1`。组件只管理展示和选择，应用层仍负责创建会话及随机抽取。切换列表内容或设置分类前调用 `TouchScroll.stop_motion()`；手机页面只有实际切换应用时才停止惯性，持续刷新状态不会打断正在进行的滑动。

通用剧情选项的取消按钮放在滚动列表外；不可取消的限时选择仍不可取消，数字键仍立即作答，不额外增加确认步骤。

## 背包

使用和快捷栏按钮保持原有直接操作。丢弃会先显示独立的「保留／确认丢弃」区域，只有确认才发送丢弃请求；该区域位于滚动列表外。重新展示背包或关闭背包会清除待丢弃项，滑动丢弃按钮不会打开确认区。

2026-11-11 合入[地面物品与背包界面](plan/地面物品与背包界面.md)后，背包改为格子＋详情两栏，确认区仍在滚动区外、页脚上方；切换选中物品也会取消待丢弃项，确认文字写明物品会留在脚边的地上。

手机应用列表的滑动用例按实际可滚范围判定（先要求列表确实溢出，再要求滑到 `min(30, 可滚范围)`），不同平台字体度量下溢出量不同（Linux 回退字体只多 9 像素），避免写死像素造成误报。

## 结局与开发工具

结局正文和插画可以滚动，结算、醒来、返回主菜单位于固定操作区，按钮最小高度为 60 个界面单位，窄窗口会自动换行。出现／隐藏醒来按钮时重新计算正文高度，打开另一张结局卡时停止惯性并回到正文开头。原有的评级、醒来条件和按钮触发的事件保持原有规则。

开发工具使用相同的触屏滚动，标题仍用于拖动整个窗口。滚动距离按窗口缩放和画布变换换算，缩小窗口不会让内容跟不上手指。切换工具分页会停止上一页的惯性；收起为悬浮球仍保留可用的滚动位置。视口尺寸改变时取消未完成的滚动手势，避免旧坐标继续触发操作。

从速通难度页进入天赋选择再取消时，如果原焦点控件已经隐藏，会把键盘焦点恢复到主菜单的新游戏按钮。该恢复只在菜单仍然打开且没有其他有效焦点时执行。

## 验证与画面

自动回归入口是 `tests/suites/selection_ui.gd`，已加入 `tests/run_tests.gd`。测试用 `InputEventScreenTouch`、`InputEventScreenDrag` 和键盘事件操作真实控件，覆盖选中与确认、滑动误触、取消／多指、随机项、速通准备、滑条、手机、档案和大字号布局。

运行检查：

```bash
python tools/check.py
```

原生截图使用实际游戏界面生成：

```bash
godot --path . --windowed --display-driver x11 --rendering-method mobile \
  --rendering-driver vulkan --script res://tools/capture/capture_selection.gd
```
